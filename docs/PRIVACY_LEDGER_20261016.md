# GaryHub v1.3.4.0 · 首页资料保护与私人记账

## 只需执行这些操作

1. 将整个 ZIP 完整解压到普通文件夹。
2. 保存网站上尚未保存的编辑，双击 `RUN-UPDATE.cmd`。
3. 如提示 SSH 私钥口令，输入你以前连接 Garyhub 时使用的口令。输入过程不显示字符是正常现象。
4. 等待 `8/8 COMPLETE GaryHub v1.3.4.0`。进入 `https://tools.garyhub.uk/admin/`，设置资料访问码。
5. 打开 `https://calendar.garyhub.uk/ledger/` 开始记账。

无需复制代码、配置新域名、安装服务器依赖或填写模型 API Key。使用现有 Windows OpenSSH、服务器地址和 `%USERPROFILE%\.ssh\garyhub_interserver_ed25519`。严格核对已保存的主机密钥。

本包已经完成开发与本地测试；真实服务器的构建、检查、备份和切换由安装器执行，收到安装包并不代表服务器已经更新。本环境没有读取你的 SSH 私钥。

## 首页访问控制

- 默认启用保护，初次没有默认访问码。管理员可直接查看，并在 Tools → Admin 设置访问码。
- 姓名和身份链接、教育与毕业信息、GPA/Rank、项目、技能共五组可以分别选择保护。
- 路人或普通登录用户输入同一个管理员设置的访问码后，解锁当前受保护资料，有效 24 小时；可点击“重新隐藏”。登录本身不解锁资料。
- 原有“指定用户查看 GPA/Rank”权限保留；管理员始终有权限；这些权限与 VPN 授权独立。
- 管理员取消“启用资料保护”后，路人可直接查看全部资料。修改设置、换码或“撤销已有访客授权”会撤销旧的访客授权。
- Admin 提供“预览未授权首页”。管理员预览时也按路人权限显示。
- 未授权 HTML、标题、描述与内容接口不包含受保护资料；实际资料片段只保存在服务端非公开文件。旧静态首页备份路由不再公开。
- 授权按浏览器会话记录。更换浏览器、清除 Cookie 或登录会话被重建后，可能需要重新输入访问码。服务端每次请求检查授权；页面每 10 秒及返回标签页时刷新。已经看到或复制的信息无法收回。
- 访问码修改后不会回显，数据库仅保存随机盐和 scrypt 校验值；错误尝试有限流。

注意：现有 GitHub 仓库是公开仓库，旧版本中曾有个人资料。本包准备的当前首页源码会移除这些明文资料，但不会删除旧提交、搜索引擎收录或外部副本。历史清理与仓库可见性变更不包含在本次安装中。

## 私人记账

Calendar 顶部及“日记、健康与记账”区域均有入口。记账独立页面包含日夜主题和手机布局。

- 支出、收入、退款；人民币 CNY（¥）、美元 USD（$）；日期、图标类别、金额、选填备注。
- 金额以整数分保存，输入最多两位小数；单笔上限 99,999,999.99。默认使用账号时区的今天，记住上次使用的币种。
- 内置餐饮、日用品、交通、住房、购物、教育、娱乐、医疗、订阅、旅行、人情等支出类别及四类收入类别。
- 可新增、改名、更换图标或停用自己的类别；停用不删除旧记录。
- 可编辑与删除；防重复创建、防旧页面覆盖新版本、防账号切换后误保存到其他账号。
- 退款可关联原消费，自动沿用币种与类别。累计退款不能超过原消费；有关联退款的原消费不能直接删除。先调整或取消相关退款，再修改受限字段。原消费选择器列出最近 1000 笔支出，更早的退款可以手动录入。
- 日期、币种、类别共同筛选明细与统计；明细每页 30 条。
- 实际消费＝支出−退款；净支出＝实际消费−收入；日均数包含起止日期和所有无消费日期。
- 退款按退款发生日期统计，当期消费和净支出允许为负。人民币与美元分别统计，不自动相加或换汇。
- 显示每日消费趋势、类别金额对比。长日期范围的趋势按连续日期区间合计显示，统计总额仍精确。
- 每个用户只访问自己的记录；管理员没有查看他人账目的额外权限。Calendar 管理员选择其他用户事项，不会改变记账归属。

## 回滚

需要撤回本次更新时双击 `ROLLBACK.cmd`。恢复此前 Calendar、Tools/Lab 镜像及首页路由；保留所有当前数据库内容，包括新记账记录和心情、日记、学习进度。

回滚会恢复旧首页的可见程度，因此首页可能重新展示原先公开的资料。新建账目表会留在数据库，但旧页面没有记账入口。若此后已经进行了别的部署或 Caddy 修改，自动回滚会停止，保护后续改动。

完整数据库备份仅用于明确的数据恢复，不会在普通应用回滚时自动覆盖当前数据库。
