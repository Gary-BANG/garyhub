# GaryHub v2.3.0.3：布丁改为可活动的骨骼角色

维护日期：2026-11-04（America/Chicago）。状态：源码已准备、本地已验证；未推送、未合并、生产未核验。基础为 v2.3.0.2 源码提交 `9c61d249a98290e1d39e993552767cce747bfe48`。

## 起因与约定

维护者认为每个角色只有一个姿势显得呆板，参考了三类效果：Shimeji 的拖拽和下落互动、Spine 的平滑过渡、Rive 上 Duo 的点击反应和待机动作。2026-11-04 与维护者约定：
- 扩展自有的 SVG 骨骼方案，不引入 Rive 或 Spine。
- 布丁不会自己走动。
- 用"摸头"互动：鼠标在头上来回移动，手机上手指在头上来回滑；单击仍然打开聊天。
- Calendar、Lab 等安静页面降低活跃度。
- 米露和栗栗保持不变。

## 美术

`characters/pudding/rig.svg`（134 KiB）的素材来自 GPT 生成的四张图：三姿势设定图、坐姿部件拆解图（含拼装图）、站姿/趴姿图、表情图（另外单独重画了困倦脸）。

- **露出的部分取自原图**：拼装好的坐姿图里每个像素，都分给在那里位于最上层的拟合部件。拟合时考虑遮挡，所有部件同时调整缩放、旋转和位置。头部区域从脸中心沿轮廓线填充得到，再按颜色把两只耳朵扣出去。所以静止时和原图完全一致；GPT 画的部件只用来补被遮住的地方，每层多带 2px 原图像素，以免露出接缝。
- **可活动的部件**：耳朵和尾巴分成根部和末端两段；抬起的右前爪是单独一块。
- **表情**：默认的眼睛和嘴取自原图。闭眼、^ ^、困倦、o 形嘴、打哈欠、w 形嘴、吐舌头，都按原图五官的位置用矢量线条画出。表情图里的五官放到原图的脸上位置对不准，所以没有采用。
- **睡觉**：使用单独的趴姿图。用部件把头降下去会露出大片从来没画过的区域，所以不走部件。
- **矢量化**：沿用栗栗的流程，12 色共享调色板 + vtracer + `slim_rig.py`。

## 动作（`companion/puppet.js`）

只对 `characters.js` 里带 `puppet` 配置的角色启用；`boot.js` 在 `pet.js` 之前加载它。

- **弹簧**：耳朵根部与末端、尾巴根部与末端、四条腿都挂在弹簧上，由身体的加速度和摆动驱动。落地时耳朵往外甩、尾巴尖抽一下；腿只在被拎起或下落时晃动。
- **待机**：呼吸起伏，头跟着鼠标转（±4°），会眨眼，尾巴轻轻摇。
- **小动作**：每 9–18 秒随机一个，包括打哈欠、摇尾巴、东张西望、抬爪、吐舌头喘气、甩耳朵。只在页面可见、展开显示、聊天面板关闭时出现。
- **摸头**：在头部范围内左右来回两次即进入，变成开心眼加吐舌头，尾巴快速摇，头偏向手的一侧；停下约 1.2 秒后恢复。触屏上，在头上按下后先水平来回滑动，就判定为摸头，不会变成拖动。
- **睡觉**：60 秒无人理会就趴下：先换成困倦脸，再在 0.3 秒内淡入趴姿图，之后靠 CSS 动画继续呼吸，帧循环可以停下。鼠标靠近、点击或聊天回复都会让它醒来并打个哈欠。
- **聊天反应**：打招呼时换上抬起的前爪挥手；困惑歪头；没听懂摇头。
- **安静页面与减少动态效果**：页面带 `data-companion="quiet"` 时只保留呼吸、眨眼、弹簧摆动和摸头；系统开启减少动态效果时，弹簧、呼吸和小动作都关闭。
- **pet.js 的配合改动**：骨骼部件交给 puppet 驱动；puppet 可以用自己的表情覆盖当前状态的表情；新增页面坐标到角色坐标的换算；判断"触屏摸头还是拖动"。

升级包只能新增或替换文件，所以布丁旧的五个姿态 SVG 仍留在服务器上，不再被引用。缩略图没有改。没有数据库结构、路由或权限变化；版本号与资源 `?v=` 改为 2.3.0.3。

## 安装后

以订阅用户或管理员账号，在伙伴面板的"换个伙伴"里选布丁：
1. 切到重力模式，从高处松手，看耳朵和尾巴的甩动。
2. 鼠标在它头上来回划几下。
3. 放着一分钟，看它趴下睡觉；再把鼠标移近，看它醒来。
4. 到 Calendar 页确认它不会自己做小动作。
