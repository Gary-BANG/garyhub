# GaryHub v2.0.1.0：五位网站伙伴

维护日期：2026-11-03（America/Chicago）。基础版本 v2.0.0.0（`3a8f4f7060f2054ddd33cc994f1a7b4c63f62ddc`，安装器 r2）。状态：源码已准备；生产未核验。

## 用户看到的变化

| 角色 | 素材 | 谁可以选 |
|---|---|---|
| 米露 Milu（布偶猫） | 分层矢量 rig（v2.0.0.0） | 所有访问者（默认） |
| 栗栗 Lili（松鼠） | Step 1b 矢量姿态 | 登录账号 |
| 布丁 Pudding（小狗） | Step 1b 矢量姿态 | 订阅用户、管理员 |
| 页芽 Pagey（纸页精灵） | Step 1c 设定图裁切的 WebP 帧 | 订阅用户、管理员 |
| 小航 Navi（天空信使） | Step 1c 设定图裁切的 WebP 帧 | 订阅用户、管理员 |

- 聊天面板右上角 ⋯ →“换个伙伴”打开选择面板：显示五位角色的缩略图与一句介绍；当前账号不可用的角色灰显并注明“登录后可用”或“订阅用户可用”。
- 切换时新角色加载完成后替换旧角色，位置、模式与对话保留，新角色在对话中打招呼。选择写入 `garyhub_companion` Cookie 的 `char`，在各子站同步。
- 退出登录、订阅到期或切换到权限较低的账号时自动回到米露；再次具备权限时恢复上次选择。没有订阅等级的旧能力组合（1.3.4.1）中，只有管理员可用订阅角色。
- 新角色支持拖动、自由放置、重力下落、开伞、落地与起身、聊天反应与键盘操作；它们以整张姿态切换，配合整体摆动、压缩、轻跳与倾斜。页芽和小航有挥手、疑惑、未匹配的反应姿态；布丁和栗栗用轻跳与倾斜表示。新角色没有独立眨眼。

## 实现与边界

- `characters.js`：`kind:'rig'`（米露）或 `kind:'frames'`（其他四位，每个姿态 `[文件, x, y, w, h]`）；`tier` 为 guest／member／subscriber，`allowed(id, user)` 判断。权限只控制界面选项，角色图片与其他页面资源一样公开。
- `pet.js`：新增整张姿态渲染、`destroy()`、共享聊天面板；姿态图片以 load 事件判定就绪，只在角色被选中时加载。
- `panel.js/css`：角色选择面板、`setHandlers()`；`boot.js`：角色偏好、权限回退、未完成切换可被新请求取代、10 秒加载超时。
- `lab-service/server.cjs`（及 1.3.4.1 覆盖）：`.webp` → `image/webp`。
- 角色文件：米露 225 KiB，栗栗 295 KiB，布丁 265 KiB，页芽 163 KiB，小航 185 KiB（未压缩，选中才下载）。

## 安装与回滚

1. 两个服务须实际运行 v2.0.0.0（已安装 v2.0.0.0-r2）；否则安装器停止，不做改动。
2. 完整解压 upgrade ZIP，双击 `RUN-UPDATE.cmd`。隔离检查 `companion-http.cjs` 按清单逐个比较两服务的角色文件字节与类型；上线后校验资源哈希、页面标签、缓存、WebP 类型与首页白名单，并发布站内通知。
3. `ROLLBACK.cmd` 恢复 v2.0.0.0，保留当前用户记录。
4. `PUSH-TO-GITHUB.cmd` 推送 `update/garyhub-v2.0.1.0` 审查分支，不强推、不自动合并 main。

验证范围与限制见 [GARYHUB_V2_0_1_0_TESTS.md](GARYHUB_V2_0_1_0_TESTS.md)。
