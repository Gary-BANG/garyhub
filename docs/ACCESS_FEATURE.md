# GaryHub 网络授权功能

状态：接入代码和批量部署包已完成，本工作区未连接生产服务器执行安装。此前 HTTPS/WSS 入口已由用户安装并通过 v2rayN 下载测速。此次安装包仍需由用户在服务器执行，并完成一个真实 Calendar 账号的兑换与订阅验收。

## 使用流程

1. 打开 `https://lab.garyhub.uk/access/`，使用自己的 Calendar 账号登录。账号密码复用，登录会话仍按站点独立保存。
2. 管理员在同一页面填写闲鱼店铺首页的完整 HTTPS 链接。用户点击跳转后在店铺沟通、交易；本站不自动判断付款。
3. 管理员核实实际收款后生成 7 天、30 天、365 天或永久邀请码。邀请码单次使用，明文只在生成时显示，数据库保存其 SHA-256 哈希。
4. 用户兑换，服务器通常在一分钟内开通独立 UUID；未到期续费累加，到期后从兑换时开始计时。已停用的授权再次兑换会生成新凭据并从新期限开始。
5. 页面显示个人订阅地址和当前节点。点击复制，在 v2rayN 主窗口按 Ctrl+V 导入。浏览器直接唤起客户端的 URI 兼容性没有确认，界面不冒充已完成自动导入。
6. 到期或管理员停用后，本地同步器从 Xray 移除凭据并重启服务，已导入的节点和存量连接随之停止。重置订阅会同时更换 UUID 和订阅令牌，旧订阅立即拒绝，旧节点在下一轮同步后失效。

## 本版本的边界

- 面向单进程、小规模使用。JSON 文件由 Lab 单进程写入，主机同步器只读。不要同时运行多个写入该数据文件的 Lab 实例。
- 同步任务在每轮结束后约 15 秒再次运行。凭据有变化时重启 Xray，所有 Xray 连接会短暂重连；生成邀请码和修改店铺地址不会触发重启。
- 一分钟是正常运行时的预期，不是故障时的保证。同步失败时页面显示未确认状态，订阅接口停止返回连接；同步器会继续重试。生产验收应检查到期后实际连接停止。
- 无流量计费、限速或设备数量限制。不能把这一版宣传为包含这些功能。
- Calendar 账号的禁用/删除依赖原系统会话机制；停用 VPN 授权请在此页面显式执行“停用”。
- 订阅令牌属于凭据。订阅走 `https://vpn.garyhub.uk/sub/<token>`，Caddy 对该路径跳过访问日志，接口禁用缓存，管理员列表不返回用户 UUID 或令牌。
- Xray 的手动测试用户和旧 8080 入口在初次安装时保留，方便完成迁移。确认个人账号节点可用后，可运行收尾脚本撤销测试用户并移除旧入口。

## 部署与备份

运行 `access-host/run-install.sh`（root）。它会比对当前 Lab 源码与上传原版的哈希；不匹配时停止，避免覆盖后续修改。构建基于当前运行镜像，只覆盖本次相关文件，保留 Python Lab 运行资源。停止 Lab 后备份数据，再切换容器，安装同步任务并校验 HTTPS 路由；失败尝试恢复旧容器、Xray 和 Caddy 配置。

- 当前 Compose：`/opt/garyhub-access/compose.json`。后续管理新 Lab 容器请使用它，旧发布目录的 Compose 不会自动更新。
- 同步程序：`/opt/garyhub-access/reconcile.py`。
- 同步配置：`/etc/garyhub-access.json`。
- systemd：`garyhub-access-sync.service` 和 `garyhub-access-sync.timer`。
- 授权及邀请码：`/opt/my-services/lab-data/access-entitlements.json`，包含用户连接凭据，纳入加密备份，不提交 Git。
- 同步确认：`/opt/garyhub-access/runtime/status.json`，以只读目录挂载给 Lab。
- 安装日志：`/root/garyhub-access-install.log`；私有备份与详细错误：`/root/garyhub-access-backup-<时间>/`。
- 旧容器以 `garyhub-lab-before-access-<时间>` 保留，禁用自动重启。不要让两个容器同时写同一数据目录。
- 源码、当前 Compose、同步配置、Xray 和 Caddy 文件应一并纳入恢复计划。既有 Lab 数据备份不等于已经备份新同步器配置。

## 已执行的本地检查

- Python 同步测试：仅保留有效用户、保留原有手动用户、无效授权数据移除托管用户、重启失败恢复原配置。
- 部署模拟：成功、候选校验失败、切换后校验失败回滚。收尾模拟：移除旧入口/测试凭据、重启失败回滚。
- 模拟使用替代的系统命令；不等同于已经在 VPS 上完成真实安装或用户验收。
