## 浏览器验证（本地合成数据，`dist/local-stack.cjs` 的 games 前门转发 WebSocket）

- 大厅：两张新卡片、房间码加入框、徽标；中英文。
- 创建词语默契房间，另一侧由脚本以 `check_bob` 经同一前门加入（准备、出词、复核）：开始、提交后锁定、对方“已提交 ✓”、同时揭晓与翻牌、限时变红、复核按钮与对方选择、禁用词（“天 气！”被拒，输入保留）、第 2 轮写出同一个词后的结果页（评价“心有灵犀”、词链、房间战绩）。
- 网络栏：两人的中位数与波动、“你们之间约 92 ms”（脚本上报 180 ms）；连接状态与延迟徽标。
- 掉线：直接结束对方进程（不发关闭帧），约 10 秒后横幅“等待 check_bob 回来，计时已暂停”、计时停在“已暂停 0:43”；对方重新连接后横幅消失、计时从剩余时间继续，对方已提交的词保留。**此项发现并修复一处缺陷**：升级后的 HTTP 套接字允许半关闭，只发 FIN 的对端原本要等 45 秒心跳才被发现；现在 Calendar 与 Lab 都在收到 FIN 时立即关闭，并补了三层测试。
- 对战猜数字：添加“电脑·精明”、开始、刷新页面后回到原局、数字键盘设密码与猜测、双方历史与提示（与最终公开的密码核对一致）、草稿板、认输后的结果页（双方密码、房间战绩）。
- 375 px 手机布局（猜数字全流程）、夜间模式、“我的房间”列表；控制台与服务日志无错误。
- **隔离套件发现并修复**：共享 `auth-redirect.js` 未列入 `/play/`，未登录打开邀请链接登录后会回到日历首页；已加入两份副本，并让本版适配器按新列表核对 v2.4.2.0 的运行标记。
