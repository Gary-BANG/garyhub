# GaryHub v2.4.4.2 · 个人网站选一次，以后点名称打开

在 Tools 的「个人网站导航」里添加 HTML、文件夹或 ZIP，勾选「保存到我的导航」后，会出现「在此浏览器保留副本」。勾选后，GaryHub 将所选网站用到的受支持文件保存在这台设备的浏览器里。普通文件选择和拖入的网站都可以用这种方式保存。

## 已经收藏的题库

打开旧题库卡片。若它显示「待关联本机文件」，选中原来的网站文件夹、HTML 或 ZIP，确认入口，保留「在此浏览器保留副本」，再点「关联并打开」。原卡片就会显示「已存本机副本」。以后用同一账号和浏览器资料点名称，即可重开。已经有可读文件授权的旧卡片仍能打开原文件，点「关联」可以为它也保存副本。

## 打开、更新与删除

| 选择 | 下次打开时 |
|---|---|
| 只打开一次 | 完成本次阅读后释放文件。访客也能使用。 |
| 保存书签并保留本机副本 | 有可用授权就读取最新原文件。使用普通选择、原文件移动或授权过期时，可读取已保存的副本。阅读器会标明「本机副本」。 |
| 保存书签并取消本机副本 | 原文件授权有效期间可直接读取。普通文件选择只能留下书签，再次打开时要补选。 |
| 更新副本 | 在卡片点「更新副本」，选择新内容，确认入口并保存。有空间写入后才替换旧副本。 |
| 移除书签 | 删除账号书签及当前浏览器中该网站的副本。其他浏览器下次登录该账号并刷新导航时清理相应副本。磁盘上的源文件仍然保留。 |

题库同时有图片、脚本或讲义时，应选择整个网站文件夹或它的 ZIP。单选一份 HTML 只能带入这一份文件。目录保留相对路径和所选入口。沿用 ZIP 最大 96 MiB、单个文件 48 MiB、所支持资源合计 192 MiB 的限制。

账号只同步名称、来源、入口等书签信息。网站内容占用用户本机磁盘，服务器不保存题库文件。仅保存一个路径不能让普通文件选择器跨会话自动读取该路径。换浏览器、资料或设备，清除 GaryHub 站点数据，或浏览器回收站点存储后，需要重新关联。导航和账号仍需要正常访问 GaryHub。

## 授权和阅读器

Tools 在原设备检测到原文件授权过期时，在账号通知中心生成一条提醒。同一网站、设备和失效时段共用一条通知。有副本时仍可直接打开题库。要恢复读取最新原文件，在通知中心进入卡片，点「重新授权」。普通文件选择没有对应的原文件授权，不产生到期通知。

阅读器的全屏操作现在作用于包含工具栏和网页的内容区。受限环境会展开阅读器，退出后可继续在导航中操作。

## 安装、回滚和源码

本包严格从运行中的 v2.4.4.1 更新到 v2.4.4.2。完整解压后双击 `RUN-UPDATE.cmd`。两服务还在 v2.4.4.0 时先安装 v2.4.4.1-r1。回滚入口为 `ROLLBACK.cmd`，服务恢复 v2.4.4.1 后保留当前数据。旧版本识别书签和原文件授权，浏览器副本需使用支持副本的版本打开。

公开源码审阅基线为 PR #56 的 main `1aa5eca38991db74cc8c648b8e44386eb785858f`。上一份 v2.4.4.1 交付源码提交为 `130ca0eb2876fbf229ff5d76c873bd3c5c8d688d`，其完整树为 `0a4525d23acbf7ad870c03361b217a674103ec48`。适配器通过上一份源码补丁重建这棵树，以其文件校验两个运行能力组合。随包的源码同步入口可以从上述两棵树分别导入本次源码。实际部署、GitHub 合并和通知接收人数以现场输出为准。
