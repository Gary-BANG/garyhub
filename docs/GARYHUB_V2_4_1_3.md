# GaryHub v2.4.1.3 · 统一页头、今日面板、全站搜索与日常提醒

源码基于 main `2d1977503a74d921e7c4f6005e181c46da14ca6f`（PR #45 合并的 v2.4.1.2），独立分支 `update/garyhub-v2.4.1.3`。安装器 v2.4.1.3-r1 严格要求两服务实际运行 **v2.4.1.2**（2026-11-16 tools 与 calendar 的 `/health` 均返回 2.4.1.2）。源码已准备、本地验证；尚未推送、合并或部署。

本版按维护者 2026-11-16 选定的改进清单实现，分为界面与功能两组。

## 界面

### 统一页头与标志

- **共享样式与菜单**：`brand.css` 定义行星标志、页头高度、胶囊按钮和卡片圆角；颜色仍取各页自己的主题变量。主页的星空、工具台的纸张、Calendar 的浅蓝和登录页的深棕保留，但标志、页头结构和按钮形状一致。
- **同一个标志**：29 个页面的 “GaryHub.” 文字标志和主页的渐变标志统一成 `a.brand.gh-brand`（行星图形加 “Gary Hub”）。A 股页也换成了它。
- **手机页头一行**：`hub-nav.js` 在 760 px 以下把导航收进右上角的菜单按钮，页头只留标志、账号按钮和菜单。主页的“更多”菜单在手机上平铺进同一个菜单。
- **覆盖范围**：主页、开发者页、工具台、登录、注册、Calendar 各页（日历、日记、健康、记账、固定开支、待办、音乐、订阅阅读），以及 Tools 的网络访问、用户管理、AI 日志、服务器监控、2FA。

### 站点图标与添加到主屏

- **图标**：`favicon.svg` 与 `icons/` 下的 192、512、可遮罩 512 和 180 px（Apple）图标由 `scripts/branding/make_icons.py` 生成。脚本不依赖第三方包，重跑结果逐字节相同。
- **Manifest**：主页／Tools 和 Calendar 各有一份 `manifest.webmanifest`，全部页面都加了 icon、apple-touch-icon 和 manifest 链接。手机浏览器可以把站点添加到主屏幕。

### 主页“今日”面板

- **内容**：登录后，主页第一屏是收窄的标题、“今天”四张卡片（今日日程、未完成待办、在读讲义、未读通知）和入口卡片。访客仍看到原来的欢迎页。
- **数据来源**：日期按账号时区计算。日程只算未完成且覆盖今天的事项，另显示逾期数。“在读讲义”取学习中心中状态为“学习中”、读得最远的一讲。
- **首屏不闪**：上次登录过的浏览器在第一次绘制前就用紧凑布局；退出后清除这个标记。

### 全站搜索

- **入口**：页头的搜索按钮，或快捷键 Ctrl+K／⌘K／`/`。目前在主页、开发者页、工具台和 Calendar 首页。
- **工具与页面**：在浏览器内匹配，只列当前账号能打开的工具。
- **个人记录**：登录后经 `/api/hub/search` 查当前账号的日程（标题和备注）、待办（标题和子要点）、日记、账本备注和科研词典（中英文术语和释义）。从主页或工具台搜索时还会加上学习中心的讲义标题。
- **打开结果**：日程定位到当天，日记打开当天，账本打开那一笔，词典打开对应的 Research。
- **安全**：结果全部按文本渲染；`%` 与 `_` 按字面匹配；每个地址每分钟最多 90 次。

### 登录来由

从受保护页面跳到登录页时，登录卡片显示“登录后将继续前往「Markdown 预览」”这类提示。中英文跟随页面语言；直接打开登录页时不显示。

### 免登录的本地工具

- **对访客开放**：图片局部消除、Markdown 预览和 PDF 浅灰转换只在浏览器本机处理文件，现在不登录也能打开。
- **不变的部分**：CSP 不变，`connect-src 'self'` 仍限制连接。从学习中心打开私人讲义仍要求登录且账号一致。
- **工具台标记**：访客看到这三个工具后面标着“免登录”。

### 开发者档案公开卡

- **访客看到的内容**：当前访问者没有任何可见栏目时，页面显示一张公开卡片（名字、一句话、可公开浏览的课程网站链接），下方说明其余栏目按授权开放；有访问码时附输入按钮。
- **文案位置**：卡片文字在 `lab-service/public/developer/public-card.json`，不含私人资料，可以直接修改。
- **可见范围不变**：管理员在“开发者档案访问控制”中开放的栏目照常显示。

## 功能

### 日历订阅（ICS）

- **入口**：Calendar →“账号与提醒设置”→“日历订阅”。生成的只读地址形如 `https://calendar.garyhub.uk/feed/<32 位随机令牌>.ics`，可以在手机或电脑日历中“通过 URL 订阅”。
- **订阅内容**：包含近 400 天以来及以后的事项，全天事件；已完成的事项标题前加 ✓。
- **地址安全**：地址只在生成时显示一次，服务器只存它的 SHA-256。重新生成或关闭后旧地址立即失效，账号停用或待删除时也会失效。

### 浏览器推送

- **开启**：在“账号与提醒设置”→“浏览器推送提醒”中为当前设备开启。事项提醒按邮件提醒的同一时间推送，A 股到价提醒也会推送。iPhone／iPad 需要先把 Calendar 添加到主屏幕，再从主屏幕打开后开启。
- **实现**：`push-api.js` 用 Node 自带的 crypto 实现 Web Push 加密（RFC 8291，aes128gcm）和 VAPID（RFC 8292），没有新增依赖。VAPID 密钥在第一次使用时生成并存进数据库。
- **限制**：订阅地址只接受 FCM、Mozilla、Apple 和 Windows 的推送服务。推送服务返回 404／410 时自动删除该订阅，同一账号最多保留 10 台设备。
- **Service worker**：`/sw.js` 只负责显示通知和点击后打开页面，不缓存、不拦截请求。

### 账本预算、趋势与导出

- **预算**：记账页新增“月度预算”。可以为“全部消费”或某个支出类别设置预算，按所选汇总币种折算，显示已用、剩余或超出；月份取筛选的开始日期。
- **趋势与导出**：同一面板有近六个月的实际消费趋势，以及“导出所选日期 CSV”。CSV 带 BOM，便于 Excel 打开；以 `=`、`+`、`-`、`@` 开头的备注会加前缀，防止表格公式注入。
- **一致性**：沿用账本自己的连接、账号头检查和串行写入队列。

### A 股到价提醒

- **设置**：个股详情新增“到价提醒”，可以设置“涨到或高于”或“跌到或低于”某个价格。普通订阅最多同时保留 3 个未触发的提醒，A 股 VIP 20 个。
- **触发**：交易时段（北京时间工作日 9:30–11:30、13:00–15:00）每分钟检查一次。触发一次后发送 `tools` 分类的站内通知，开启推送的设备也会收到。
- **权限**：接口位于现有的订阅门之后，非订阅账号返回 403。

## 数据库与兼容

- **新表**：`calendar_feeds`、`push_keys`、`push_subscriptions`、`push_reminder_log`、`stock_alerts`、`ledger_budgets`，都以 `CREATE TABLE IF NOT EXISTS` 创建，没有指向 users 的外键。按账号的五张已加入账号删除清单。
- **回滚**：回滚到 v2.4.1.2 时这些表保留但不再使用，旧版的账号删除检查不会被它们阻塞；只是在旧版删除账号时，这几张新表里的记录不会一起删除。
- **后台任务**：推送提醒和到价检查在 Calendar 进程内每分钟运行一次，Calendar 重启后自动继续。
- **无其他变化**：没有新依赖，Caddy、Compose 和环境变量都不变。日历订阅地址沿用现有的 `APP_BASE_URL`。

## 安装、回滚与源码

- **安装**：完整解压 `GaryHub_v2.4.1.3_upgrade.zip`，在 Windows 双击 `RUN-UPDATE.cmd`。版本、源码、能力组合或有效 Compose 不匹配时，安装器在改动前停止。
- **核对链**：适配器 `scripts/releases/v2.4.1.3/` 以 `prior_0412.py` 载入 v2.4.1.2 的全部核对。唯一替换的是共享运行时“本地工具对访客跳转登录”这一项，改为核对访客得到页面且带 CSP。另核对新接口的登录门和 Origin 门、三个主机的 manifest、容器中的新文件，以及 Calendar 已创建的新表。
- **隔离检查**：共十二组，`useful-http.cjs` 换成本版，新增 `extras-http.cjs`。
- **站内通知**：三条，分类为 home、calendar、tools。
- **回滚与源码**：`ROLLBACK.cmd` 恢复 v2.4.1.2 应用并保留当前记录；`PUSH-TO-GITHUB.cmd` 准备审查分支，不强推、不合并 main。

构建：`python scripts/updater/manage.py build --release 2.4.1.3 --output <ZIP绝对路径>`（在 `core.autocrlf=false` 的 LF worktree 中）。验证范围与未验证项见 [GARYHUB_V2_4_1_3_TESTS.md](GARYHUB_V2_4_1_3_TESTS.md)。
