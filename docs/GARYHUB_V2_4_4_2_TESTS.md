# GaryHub v2.4.4.2-r1 验证记录

## 浏览器与文件

在 Chromium 158、两个回环地址上的 GaryHub 服务和测试账号下运行。账户、书签接口、IndexedDB、浏览器资料目录、页面和文件选择输入框均使用实际实现。原生读权限转换采用可控结果，其文件句柄能在真实 IndexedDB 中序列化。未使用生产账号，未读取用户电脑里的 ECE 310 题库。

| 检查 | 观察到的结果 |
|---|---|
| 旧版复现 | v2.4.4.1 普通选择后可留下没有持久文件授权的书签。打开网页后点击全屏，Chromium 确实显示截图里的 `Dialog elements are invalid`。 |
| 同浏览器重启 | 保存普通选择的独立 HTML、多页面中文题库文件夹、ZIP。删除测试用原件，完全退出 Chromium 并使用同一资料目录重启。点卡片均进入阅读器，文件选择弹窗次数为零。目录和 ZIP 的样式及下一题链接有效。 |
| 真实课程包 | 从普通文件选择导入 ECE 470 学习包，删除测试用的外部副本，重启浏览器，从已存副本打开。题图、KaTeX 及讲义 PDF 第 21 页正常。ECE 310 使用合成多页目录，个人真实课程文件未写入发布包。 |
| 原有书签和选择 | 使用 v2.4.4.1 格式的旧记录，无句柄也无副本。一次关联后保留原 ID，重启后直接打开。只打开一次不创建记录；关闭副本选项后普通书签仍可按需关联，原生目录授权仍可重用。 |
| 授权、通知、内容优先级 | 已授权时修改原文件，立即重开可见新内容。模拟授权过期后打开已存副本，授权弹窗调用为零。重复检查仅产生一条通知，主动重新授权后读取新内容并清除提醒。 |
| 替换与隔离 | 模拟副本写入发生配额错误，页面给出提示，原内容可继续打开。恢复写入后替换内容并刷新验证。另一账号看不到原书签，另一个浏览器资料只能看到书签并提示一次关联。同设备移除、其他设备移除后的同步都会清理本机数据。提交给书签接口的请求仅有元数据字段。 |
| 阅读器 | 工具栏与网页一起进入和退出浏览器全屏。模拟拒绝全屏时，在 375 像素宽页面内展开阅读器，返回导航无残留错误。 |
| 原有操作 | 普通选择兼容原生选择器拒绝、取消、缺失、迟到结果、手填名称及嵌套目录。仅保存原文件关联模式保留通知中心跳转、搜索、改名、移除及网址打开。 |

## 主要复现命令

在仓库根目录运行，浏览器测试使用临时服务和发布配置中的账号种子。

```sh
python scripts/updater/manage.py check
python scripts/releases/v2.4.4.2/tests/adapter.test.py
node --test scripts/releases/v2.4.4.1/tests/folder-input.test.mjs
python scripts/releases/v2.4.4.2/tests/browser-copies.py --browser /path/to/chromium --course /path/to/ECE_470_Homework_Learning.zip
```

未接入用户的 Windows 桌面或生产服务器。正式执行双击安装、上线状态、真实接收人数和用户自己的 ECE 310 内容应以现场结果为准。
