# GaryHub v1.4.3.1：学习中心与 Markdown 阅读

## 安装器 r3 修正

r2 在 1/8 因有效 Compose 路径与部署索引不一致而停止，尚未再次构建或切换。r1 回滚使用备份的 Compose 文件启动旧镜像，却原样复制了记录旧路径的索引；服务恢复了，索引路径没有同步。

r3 的标准回滚会核对实际镜像、项目／服务和路径标签后更新索引，并通过严格预检再报告完成。针对本次遗留状态，r3 在正常预检发现不一致时，只读取指定 r1 的包清单、部署状态、原索引和备份配置：要求该包与已交付 r1 完全匹配，状态已 rolled-back，索引未被其他操作修改，两服务仍为记录的旧镜像且使用准确的备份路径，解析后的完整 Compose 与原配置等价，Caddy 也未变化。全部条件通过才保留原索引的受限审计副本并原子对齐路径。

该对齐不会切换镜像、重启服务、修改 Compose、Caddy 或用户数据；后续安装仍执行完整版本／源码／配置核验、隔离验证、备份、切换、HTTPS 和通知。任何不明镜像、配置、路径或证据变化仍停止。完整解压新的 v1.4.3.1-r3 包后运行其中 RUN-UPDATE.cmd，不需要手动编辑服务器索引或重复回滚。r3 采用独立缓存和服务器目录。

## 安装器 r2 修正

r1 用户现场输出显示：已通过版本／源码核对、离线构建、隔离验证、备份及切换，6/8 校验 Markdown Viewer 的 index.html 时失败，随后自动回到 v1.4.3.0 并保留当前记录；未发布本次通知。

原因是该 HTML 需要登录，r1 将未登录的正常 302 响应当成文件正文计算哈希。r2 保留登录保护：公开资源仍校验 HTTPS 正文；该 HTML 同时核对运行容器内的文件 SHA-256 和 HTTPS 302 的登录地址／返回目标。隔离验证另检查登录后 HTTP 响应的实际字节。

修订包使用 `v1.4.3.1-r2` 独立缓存和服务器目录。完整解压新的 ZIP 后运行其中的 RUN-UPDATE.cmd 即可，现场仍要求实际 v1.4.3.0；已报告回滚完成时不需要再手动回滚 r1。应用功能、数据库和通知发布号保持不变。r2 实际上线结果仍待运行输出。

## 使用变化

- Study Hub 左栏的课程／讲次列表可通过图标收起、展开；默认展开，之后记住当前浏览器选择。收起时正文使用释放的宽度，恢复按钮始终可操作。此设置不改变成绩规划页布局。
- Lecture Notes 新增“在Markdown Viewer查看”。新标签页读取当时选中的讲义及课程内已导入配图，原页保留。链接只含编号，既有登录接口检查账号和课程／讲次归属；无需重新上传或另存副本。
- Markdown Viewer 将 h1–h6 的文档章节默认收起，点击标题或键盘 Enter／Space 独立控制。“全部展开”位于“展开源码”左侧，展开后可“全部收起”。标题前的引言和无标题文档正文继续可见；代码块内的 # 不作为标题。
- 收起父章节包含正文和下级章节，展开父章节不强制展开每个子章节。窄目录栏默认隐藏，图标展开后按标题层级缩进展示全部标题；点击目录会展开祖先和目标、定位并标记。重名标题和跳级标题独立处理。
- 编辑源码时保留仍能匹配的章节展开状态；打开其他文档恢复全部收起。源码面板继续独立显示，桌面可与目录及预览同时使用；手机上目录置于正文上方的有界面板，避免压缩正文。
- 沿用本地 Markdown／ZIP、表格、公式、安全内容处理与本地图片限制。Viewer 修改仅留在本次页面，不写回原讲义、原文件或 ZIP。学习中心讲义在会话变化／失效时清除；检查在聚焦、恢复可见及可见页面每 10 秒执行。
