# v1.4.0.1 验证记录

日期：2026-10-23（America/Chicago）。审阅基线：`4f5611b6c1d1e6def995ef9664b0035e551a806a`，GitHub main 已合并 v1.4.0.0（PR #17）。用户反馈新版页面可运行，但鼠标悬停无效果；尚无现场部署日志可核验镜像、Compose 与实际通知人数。

## 复现与修复

在同一 jsdom 页面把主要 hover/pointer 媒体查询置为 false，向 Markdown 链接派发鼠标 pointermove：v1.4.0.0 选中项为 0、简介隐藏；调用键盘聚焦后选中项为 1、简介出现。它复现了用户反馈的交互模式，不证明用户浏览器的具体媒体查询返回值。

v1.4.0.1 删除设备媒体查询对悬停事件/动画的硬门槛；媒体查询仅决定初始提示。实际 pointerover/pointermove/mouseover/mousemove 可激活悬停，不依赖点击或 focus。触屏输入重置动画并屏蔽后续兼容鼠标事件；键盘输入独立工作。CSS 不再因主要设备为 coarse/none 强制取消鼠标放大，只在实际触摸和减少动态效果时停用。页面滚动后重新测量图标位置，传统鼠标离开也会复位。
