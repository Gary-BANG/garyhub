# GaryHub v2.3.2.0 · 学习中心

2026-11-05（America/Chicago）。安装器 v2.3.2.0-r2 从 v2.3.1.1 升级。Calendar 和 Lab 两个服务均须实际运行 v2.3.1.1。r1 在第 1/8 步版本预检停止的用户，请将 r2 解压到新目录，直接运行新包。

## 阅读与导航

- 四张学习统计卡压缩上下间距，数字在桌面和手机上以 28–36 px 显示。
- 阅读时「课程」「目录」随页面滚动保持可见。点另一个按钮切换面板，再点当前按钮收起侧栏。目录显示当前 Markdown 的全部一至六级标题，包括同名标题。没有标题或讲义时显示相应提示。
- 「收起目录层级」只折叠导航树。「收起全部正文」折叠讲义内的章节，可单独展开章节，也可一键全部展开。点击目录中的标题会打开对应章节及祖先并定位。手机上跳转后自动收起面板。
- 首页或 Tools 登录后点用户名旁的头像可直接进入「个性化」。学习中心和成绩规划共用的页头也有同一入口。外观有墨夜、纸白、暖纸；正文字号 14–28 px，一级标题 20–54 px，其余标题逐级缩放。设置沿用账号的学业数据和备份，支持已有账号及旧格式备份。
- Markdown 围栏声明的语言显示在代码栏，未声明时显示「纯文本」；「复制代码」复制原始代码。
- 讲义渲染在浏览器完成，章节折叠和目录切换不改原始 Markdown。未引入生产依赖和数据库迁移。

## 安装与回滚

1. 在 Windows 完整解压 ZIP，双击同一目录内的 `RUN-UPDATE.cmd`。安装器沿用现有 OpenSSH、SSH 私钥与主机指纹配置。
2. 安装器核验实际版本、能力组合、源码哈希和有效 Compose，离线构建并运行九组隔离验证，备份后切换，验证健康和 HTTPS，再为全部已批准且启用的账号（含管理员）发布未读通知并检查去重。若出现 STOPPED，请保留末尾日志。
3. 需要回滚时双击同一目录的 `ROLLBACK.cmd`，安装器核对部署记录后恢复 v2.3.1.1 应用，并保留当前用户数据。
4. `PUSH-TO-GITHUB.cmd` 可单独准备并推送审查分支。源码补丁以 PR #34 的 main 为起点，在独立 worktree 操作，由维护者审阅合并。
