# GaryHub v1.3.5.2 · 统一登录与固定开支

适用于已经安装 v1.3.5.1 的 GaryHub，自动保留服务器现有 TOTP 可选功能、账号、数据与部署配置。安装程序会核对实际源码和有效部署索引，未知版本在切换前停止。

## 使用方式

1. 将整个 `GaryHub_v1.3.5.2_Update.zip` 完整解压到一个新文件夹。
2. 保存网页中正在编辑的内容，双击 `RUN-UPDATE.cmd`。
3. 若提示 SSH 密钥口令，输入原来的口令，等待 `8/8 COMPLETE GaryHub v1.3.5.2`。

不需要复制代码、填写新密钥或安装服务器依赖。沿用 Windows OpenSSH 和已有 `garyhub_interserver_ed25519`；严格检查现有主机密钥。密钥口令不保存、不上传。

安装会一次完成：核对版本与部署 → 在当前实际镜像上离线构建 → 两项服务隔离联调 → 数据库一致性备份、全量 Lab 文件校验备份、真实数据副本迁移演练 → 切换两项服务 → HTTPS 验证 → 发布站内通知并检查人数与去重 → 尝试将源码提交到本机更新分支。

切换 Calendar 和 Tools/Lab 时会短暂不可用。提醒 worker、网络节点、RSS、Files 与监控沿用现有部署。

## 统一登录

Calendar、Tools、个人主页、Grade Planner、Study Hub 与 ECE 470 Lab 使用 `https://calendar.garyhub.uk/login/`。旧 Tools/Lab 登录地址继续可用，并自动转到统一入口。

登录成功后返回原模块，保留允许的页面参数和讲义锚点。返回地址限制在明确列出的 GaryHub 自有页面；外部地址、任意子域、接口、登录页循环不允许。临时密码修改后也可继续回到原页面。

“忘记密码”和“申请账号”在同一行对齐，均提供至少44像素的点击高度。邮箱验证码找回、注册审批、账号权限、共享登录 Cookie、中英文和日夜主题保持现有规则。一次登录后各自有模块共享身份；退出后其他模块在下一次请求或页面身份检查时失效，有未保存草稿时先提示保留内容。

## 固定开支

记账内新增“收支记录 / 固定开支”页签，入口为 `https://calendar.garyhub.uk/ledger/fixed/`。

每项包含名称、每次支付金额、CNY / USD / CAD / HKD、每月 / 每年、支出类别、备注和启用状态。类别沿用当前账号的账本设置。可新增、编辑、停用、删除；每账号最多300项。

固定开支仅参与独立参考估算，不自动创建实际账目，也不进入实际账本的日期范围统计。

- 月付金额乘12，得到折合全年开支。
- 年付金额除12，得到折合月均开支。
- 按类别和汇总币种查看启用项目估算；停用项目保留在列表中。
- 四种原币分别保留；换算使用现有 Frankfurter 参考汇率并显示报价日期。先逐次付款换算到分，再折算全年；月均从全年总额除12，仅展示时保留两位小数。
- 汇率不可用时展示四种原币的月均与全年估算，暂停合并折算。

估算代表“按当前费用持续支付”的负担，不代表某个自然月或自然年的实际扣款；不设置自动扣款、自动记账或付款日程。

## 记入账本

点击项目上的“记入账本”，默认带出账号时区的今天、原币金额、类别与备注。通常只需选择实际付款日期并确认；可展开“调整本次实际金额”。

确认后生成一笔普通支出，并提供“查看这笔支出”入口，自动定位相应日期与记录所在页。固定项目继续保留，供下次使用。

同一固定项目、同一付款日期最多生成一笔记录。重复点击、网络重试或不同请求编号再次提交，不会重复记账，并可打开原记录。日期由原始记账操作确定；以后在账本编辑该笔支出的日期，不会允许同一原始付款日期再次重复导入。删除该实际账目后，可重新记入。

修改、停用、删除固定项目不会改写已生成的历史支出。删除项目会清理其记账关联，保留实际账目和包含项目名称的备注。新增数据按账号隔离，管理员没有读取其他用户固定开支或账目的额外权限；账号删除已覆盖新数据。

## 源码、重试与回滚

本机完整源码、测试和说明保存在 `%LOCALAPPDATA%\GaryHub\updates\v1.3.5.2-r1`。本机仓库默认 `D:\Codes\Own_Project\garyhub-repo`；来源正确、工作区干净、基线匹配时，自动建立 `update/garyhub-v1.3.5.2` 并提交修改。源代码同步失败时保留全部源码，已完成的服务器升级不会因此撤回。

需同步 GitHub 时，双击 `PUSH-TO-GITHUB.cmd`，再在打开的页面创建、合并 PR。推送与合并不会再次部署服务器。

成功后重跑不会重复部署或通知。若只通知失败，状态为 `notification-pending`，重跑只重试通知。出现 STOPPED 时保留末尾输出，不绕过检查。

`ROLLBACK.cmd` 恢复此次更新前的应用镜像和部署索引，保留所有当前数据。旧版没有固定开支页面；新表继续保留，旧版的账号删除结构检查可能暂停删除操作，需要重装本版后操作。已有 CAD/HKD 账目仍允许回到兼容的 v1.3.5.1。有进行中的账号删除或后续部署/配置变更时，回滚停止以保护当前状态。

实际部署索引：`/opt/my-services/garyhub-active-deployment.json`；本次运行记录：`/opt/garyhub-update-v1.3.5.2-r1/deployment-state.json`。受限备份含真实数据库、配置、资料和可能的 TOTP 密钥，只留在服务器，不提交 Git。

开发环境未连接生产 SSH、未运行用户的 Windows PowerShell 或真实生产 Docker。交付测试证明开发版本的行为；实际构建、备份、HTTPS 与通知人数由安装器在服务器验证，通过后才报告 COMPLETE。
