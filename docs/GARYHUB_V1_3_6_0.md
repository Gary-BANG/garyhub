# GaryHub v1.3.6.0 · 实用工具与作业题库分发

适用于服务器实际运行 v1.3.5.4 的部署。安装器会识别并保留现有的 TOTP 或无 TOTP 版本。

## 安装

1. 完整解压更新包到新文件夹，不能直接在 ZIP 内运行。
2. 保存网页里正在编辑的内容，双击 `RUN-UPDATE.cmd`，按提示输入原有 SSH 私钥口令。
3. 等待 `8/8 COMPLETE GaryHub v1.3.6.0`，刷新 Tools 和 Lab；需要时按 Ctrl+F5。

程序连续完成版本与源码核对、离线镜像构建、合成账号隔离测试、数据备份、服务切换、HTTPS 验证、站内更新通知和本机源码同步。切换期间 Calendar 与 Tools/Lab 会短暂不可用。

沿用 Windows OpenSSH、`%USERPROFILE%\.ssh\garyhub_interserver_ed25519` 和已知主机记录，连接 root@162.35.168.17。本机默认仓库 `D:\Codes\Own_Project\garyhub-repo`。不需要复制应用代码或重新配置服务。

显示 STOPPED 时保留末尾输出，不要绕过校验。GitHub 合并状态不能替代服务器版本检查。

## 新工具

登录后在 Tools 中打开：

- **图片局部消除**：上传图片，涂抹干扰区域并修补、下载。采用本地纹理修补，复杂背景效果需要人工检查。
- **Markdown 预览器**：打开 Markdown 文档，查看排版、数学公式和源码。文件最多 4 MB；远程图片不加载，避免打开文档时向外部站点发送请求。
- **PDF 浅灰转换器**：选文件，调整偏冷灰/中性灰、亮度、DPI，预览第一页后转换并下载。最多 20 MB、100 页，另有像素上限；过大时降低 DPI 或拆分文件。受密码保护的文件请先解锁。

三个工具都在本机浏览器处理文件。PDF 输出为图片型 PDF，保留页面尺寸，但文字不再能直接选中，交互表单不保留；实际打印耗材取决于打印设置。

## 管理员分发作业题库

1. 用管理员账号进入 ECE 470 Lab，点击云端状态栏的 **分发题库**。
2. 选择自己的作业分组，例如 **Homework 1.1**，勾选一个或多个启用账号。
3. 点击 **预览分发**，核对各用户的新增、跳过数量，再点击 **确认分发**。
4. 接收用户保存当前工作后刷新 Lab，在“作业练习”里查看题目。如果提示云端冲突，先导出本机备份，再加载云端；不要强行覆盖。

分发题目模板、参考答案、解析、公式和配图，不复制管理员的作答、草稿或历史。接收人获得独立副本，之后修改互不影响。相同题目自动跳过；同编号但内容不同则生成新编号，不覆盖原题。一次分发一个分组，最多 100 个模板、50 个接收账号，沿用每账号 24 MiB 空间限制。

预览后有人保存了新进度时，分发会停止并要求重新预览。网络断开或部分保存未确认时，也请重新预览再试，已保存的相同题目会跳过。

## 源码、重试与回滚

本机仓库来源和基线匹配、工作区干净时，安装器创建并提交 `update/garyhub-v1.3.6.0`。已有改动会保留。源码同步警告不会撤销已成功的服务器部署，完整源码保存在 `%LOCALAPPDATA%\GaryHub\updates\v1.3.6.0-r1`。

需要推送 GitHub 时运行 `PUSH-TO-GITHUB.cmd`，然后创建并审查 PR；安装不自动推送或合并。

成功后重跑不会重复部署或通知；仅通知失败时重跑只重试通知。`ROLLBACK.cmd` 恢复更新前应用镜像并保留当前用户数据，包括已分发的题目。发现后续部署或配置变动时停止回滚以保护后续工作。

正式数据库、私有文件和环境配置留在服务器。部署索引 `/opt/my-services/garyhub-active-deployment.json`；本次状态 `/opt/garyhub-update-v1.3.6.0-r1/deployment-state.json`。

开发测试不代表已上线。本环境没有访问生产 SSH，未执行真实 Windows 安装或 Docker 切换；安装器会在现场核验后才报告 COMPLETE。验证明细见 TEST-RESULTS.md。
