# GaryHub v2.4.0.2 · A 股行情工作台

源码基于 main `8df09118e3f4d7a7c8d00f4c2cc79b13849ca50c`（PR #39，v2.4.0.1）。本次在独立分支 `update/garyhub-v2.4.0.2` 开发。源码准备、本地验证、GitHub 合并与生产验证分别记录；本版尚未部署服务器。

## 界面与使用

行情页 `/stocks/` 采用参考图的三栏关系：左侧图标栏、可收起的窄侧栏和宽内容区。桌面工作区上限从 864 px 扩大到 1920 px。

- 第一个图标为搜索，第二个为收藏。点击切换对应侧栏；再次点击当前图标、侧栏收起按钮或 Escape 可收起。关闭侧栏后内容区填满可用宽度。
- 搜索支持股票代码片段、名称和拼音缩写；输入停顿 280 ms 后检索，也可回车。统一全角字符、大小写、空格与沪深京代码前缀；优先返回完整代码或名称，再返回前缀、包含和顺序字符匹配，如“平银”。结果去重，最多 15 项。
- 继续使用东方财富证券建议接口；一次最多取得 50 个候选，没有命中时最多再查一次首字符。候选仅在进程内保存，最多 512 项，闲置 20–21 分钟清除。这是有界建议搜索，不是遍历全市场的拼写纠错。上游错误显示重试提示。
- 收藏侧栏先显示自己的分组；选择分组后列出该组股票，可打开详情、移出、重命名或删除分组。继续使用现有 3 组 × 每组 5 只、同股不重复、按账号保存及乐观修订号保护。切换组时保留正在看的个股详情。
- 暖色日间与暖灰夜间主题可在右上角切换，选择保存在本浏览器；盘口、图表、均线和读数同步切换。
- 详情默认展示分时和五档盘口；盘口复用报价快照。近月日 K 和财报展开时读取。宽屏分时与盘口并排，窄屏上下排列。手机侧栏覆盖主区，选择股票后自动收起，遮罩也可关闭。
- 保留数据时间、来源、缺失值、真实零、负值、成交量单位及财报累计口径。常见专业术语补充缩写：PE/TTM、PB、MKT CAP、FLOAT CAP、T/O、VR、AMP、O/H/L/PC、VOL、AMT、OHLC、MA、REV、NP、YoY、ROE 和 OCF。

## A 股 VIP

管理员在 Tools → 用户管理 → 对应用户的“A 股行情 VIP”复选框中独立设置。默认全部关闭，管理员身份不自动授予 VIP。仅开通账号在行情页右上角显示“A 股 VIP”；未开通账号不显示“普通用户”或等级标签。切回页面及每分钟检查当前权益，登录账号变化时清除旧详情并要求刷新。

VIP 与现有普通／订阅账号等级独立。本次保留行情工具原有的订阅访问条件，单独勾选 VIP 不改变账号订阅。AI 选股属于后续开发，本版只提供权益管理和标识。

`users` 增加 `stock_vip`（0/1，默认 0）和 `stock_vip_version`（默认 0），重复迁移保留原值。管理接口核对当前管理员、页面操作人、目标账号状态、账号修订号及 VIP 修订号，沿用 Origin 与 CSRF，记录管理审计。同版本并发操作发生冲突时要求刷新。账号删除清单补入已有 `stock_lists`，可正常预览和清理股票收藏。

## 安装、回滚与源码

完整解压 `GaryHub_v2.4.0.2_upgrade.zip`，在 Windows 双击 `RUN-UPDATE.cmd`。两服务必须实际运行 **v2.4.0.1**。此前最新现场证据为 v2.4.0.0；本次不把 GitHub 已合并视为服务器已更新。版本、源码、能力或有效 Compose 不匹配时安装器停止。

本版注册自己的小型适配器 `scripts/releases/v2.4.0.2/`，复用共享 `build_overlay.py`、`deploy_runtime.py`、Windows 安装入口和源码导入器，基线能力覆盖来自 v2.4.0.1；不修改共享更新器、生产依赖、Caddy、DNS 或 Compose 结构。安装执行严格预检、离线镜像构建、十组隔离 HTTP 检查、一致备份、切换、HTTPS/资源哈希及全体启用账号通知去重核对。

`ROLLBACK.cmd` 恢复安装前 v2.4.0.1 应用和有效配置，保留当前用户记录及收藏。新增的两列保留，旧版不使用它们。`PUSH-TO-GITHUB.cmd` 使用独立 worktree 和审查分支，保留现有工作区，不强推、不自动合并 main。Windows 安装、真实 Docker 切换／回滚与生产通知人数需要安装现场日志确认。

构建：`python scripts/updater/manage.py build --release 2.4.0.2 --output <ZIP绝对路径>`。验证范围见 [GARYHUB_V2_4_0_2_TESTS.md](GARYHUB_V2_4_0_2_TESTS.md)。
