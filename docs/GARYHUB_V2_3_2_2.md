# GaryHub v2.3.2.2

网站伙伴可修改日程、标记完成、记录支出和添加按月或按年的固定开支。未分类日程可直接确认，也可在对话中选择已有分类。记账需要明确币种和分类，核对卡片后保存。

安装前两服务须运行 v2.3.2.1。完整解压后双击 RUN-UPDATE.cmd。安装器核验基线、独立镜像、备份、切换、HTTPS 和站内通知。回滚使用 ROLLBACK.cmd，源码审查分支使用 PUSH-TO-GITHUB.cmd。
