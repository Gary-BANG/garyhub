# GaryHub v1.3.4.1

适用于已经成功上线 v1.3.4.0 的 GaryHub。

## 一次完成升级

1. 把整个 ZIP 解压到一个新文件夹。
2. 双击 **RUN-UPDATE.cmd**。如有提示，在本机输入已有 SSH 私钥口令；口令不会写入升级包。
3. 等待 `8/8 COMPLETE GaryHub v1.3.4.1`。然后把窗口最后的输出发回，以便核对实际服务器结果。

程序会完成：源码与版本核对 → 基于当前镜像离线构建 → 隔离数据联调 → SQLite 一致性备份和 Lab 文件逐字节备份校验 → 切换服务 → 实际 HTTPS 检查 → 向启用账号发布并校验未读站内通知 → 本地源码分支与提交。

直接复用当前容器的运行配置、环境变量、网络和数据挂载。不上载私钥，不修改提醒服务与网络节点配置，不把真实个人资料 JSON 加入代码包。下载本包本身不会更新服务器；必须执行上述入口。

## 升级后的设置

- 用户与资料管理：[Tools / Admin](https://tools.garyhub.uk/admin/)。路人、普通登录用户有独立的保护开关、默认可见分组、访问码、撤销和预览。为了保持现有隐私选择，第一次升级会把原规则复制成两套，不会自动扩大公开范围。可以将路人设为仅默认显示身份，将普通登录用户设为默认显示身份与项目。
- 旧的访问码会保留在两套规则中，旧的浏览器解锁状态会失效。建议为两类访客分别设置不同访问码。每次解锁有效 24 小时；更改或撤销只影响对应身份。管理员始终可见，指定用户的 GPA / Rank 授权继续有效。
- 用户列表显示邮箱与验证状态；没有邮箱的账号显示“尚未绑定邮箱”。密码不可查看，管理员只能生成临时密码。临时密码仅显示一次，由管理员自行转交；旧登录失效，用户必须设置新密码后才能访问个人数据。管理员自己的密码通过“修改自己的密码”入口修改。
- 保留停用/启用。删除须先查看内容清单，再输入完整用户名。账号立即停用，旧登录和订阅撤销；已有网络节点授权需等宿主机同步确认移除，才清理在线账号、日历、日记、健康、记账、Lab 与学习数据。处理中会显示进度，服务重启后可恢复；如果任务还没交给 Lab，管理员可点击“恢复删除流程”。当前管理员和最后一个启用的管理员受保护。其它账号数据保持隔离，管理员没有查看他人私人记录的接口。
- 删除清理当前在线数据；既有受限备份继续按原保留策略保存，不会借删除账号清空整站备份。最少量的操作审计与删除完成标记只保留账号编号、操作、时间，不保留密码或私人内容。
- [Ledger](https://calendar.garyhub.uk/ledger/) 的“汇总币种”合并两种币种的支出/收入/退款，并统一换算实际消费、净支出、日均、趋势和分类。明细保留原币金额，同时展示折算金额。
- 汇率来自 Frankfurter v2 官方来源汇总，每天按需获取，只覆盖一个最新缓存。页面标注报价日与获取时间；节假日或尚无新报价时显示最近公布汇率。网络失败时有缓存则继续使用并注明日期；没有有效汇率则保留记账和原币明细，暂停合并统计。
- 历史区间也统一使用页面显示的最新参考汇率，不做历史汇率估值。逐笔折算到分后合计，平均值按含首尾的自然日数计算。参考汇率不含银行/支付手续费。

## GitHub 同步

升级完成后，若 `D:\Codes\Own_Project\garyhub-repo` 干净且匹配已部署的 v1.3.4.0 源码，会创建并提交 `update/garyhub-v1.3.4.1` 分支。原有 v1.3.4.0 提交留在该分支历史中，即使此前尚未推送，也可一并推送。

本地提交不会自动改变 GitHub。需要同步时双击 **PUSH-TO-GITHUB.cmd**：会推送此分支并打开对比页面。要让 `main` 更新，仍需在 GitHub 创建并合并 PR。若本地存在未提交改动或基线不同，不会覆盖；服务器更新仍完成，源代码、测试和说明保留在 `%LOCALAPPDATA%\GaryHub\updates\v1.3.4.1`。

## 回滚与重试

- 部署切换后检查失败，会尝试恢复原应用镜像，保留当前数据库与用户数据。通知失败时无需回滚，重新运行相同安装器可重试，通知不会重复。
- 手动回滚双击 **ROLLBACK.cmd**。它核对镜像与当前部署索引，避免覆盖后续更新。存在待完成的账号删除或启用账号的临时密码待修改时，拒绝降级：先完成这些流程，再回滚。
- 回滚不恢复已删除账号，也不覆盖新账目；旧版本的首页会采用兼容的锁定规则，需在旧 Admin 重新设置。恢复完整历史备份应另行审查，不能使用普通回滚代替。
- 出现 `STOPPED` 时保留最后输出，不跳过校验。服务器私密记录目录：`/opt/garyhub-update-v1.3.4.1/private-backup/`。重复运行同一成功包不会再次部署或重复发通知。
