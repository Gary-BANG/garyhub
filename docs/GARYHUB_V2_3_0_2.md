# GaryHub v2.3.0.2：栗栗改为骨骼角色，伙伴落地更平稳

维护日期：2026-11-04（America/Chicago）。状态：源码已准备、本地已验证；未推送、未合并、生产未核验。基础为 v2.3.0.1 源码提交 `5a45333942b7d2602f4645f328d6caea535a49b2`。

## 问题

维护者反馈几个整张姿态图角色（栗栗、页芽、小航、布丁）落地后的动作不连贯。逐帧记录后找到三个原因：

- 落地时降落伞摆动留下约 6.7° 倾角。身体绕头顶上方的挂点转回直立，脚已着地却随之横移约 13 个屏幕像素。
- 整张姿态图一帧之内换成蹲姿，伞和背带瞬间消失，约 1 秒后又直接切回站姿。
- 页芽、小航的开伞图比站立图约小 20%，落地瞬间整个角色变大一圈；栗栗的站立图朝右，其余姿态朝左。

## 修改

- **栗栗改为分层矢量骨骼角色**（`characters.js` 中 `kind:'rig'`，与米露相同）。`characters/lili/rig.svg` 来自 GPT 生成的部件拆解图和表情图：身体、手、耳朵取自部件图；尾巴从拼装图中抠出，被身体遮住的根部补同色毛；头部以闭眼头为底去掉五官，另有睁眼、闭眼、^ ^ 开心眼、微笑、o 形嘴五层。各层用 vtracer（共享 12 色调色板）矢量化，再经 `scripts/companion/slim_rig.py` 精简为 187 KiB。旋转中心与上限：头 4°、耳 2°、尾 3°（尾巴大，转多会露出藏在头后的部分）、爪 7°。缩略图未改。
- **落地前收住摆动**（`pet.js`）：开伞下降或自由下落的最后 200 px 内，摆动目标按距离降到 0。实测着地倾角：栗栗 0.65°、米露 0.94°（此前约 6.7°），空中仍约 4°。对所有角色生效。
- **整张姿态角色**：pet.js 在落地与起身时让旧姿态图在新图上方 160 ms 淡出（由帧循环驱动，页面不绘制时不会卡住），并只对蹲姿图做轻微挤压、去掉起身的小跳，蹲姿时间由约 1.06 s 缩短为约 0.7 s。页芽、小航的开伞图放大 1.2 倍，小航的落地图缩至 0.93 倍，使头部与站立图同大。可选的 `touchdown`／`squash`／`rise` 落地帧（`LANDING_FRAME`）保留在引擎中，目前没有角色使用。
- 升级包只能新增或替换文件，所以栗栗旧的五个姿态 SVG 仍留在源码和服务器上，但不再被引用。

没有数据库结构、路由或权限变化；版本号与资源 `?v=` 改为 2.3.0.2。

## 安装后

登录账号，在伙伴聊天面板的设置里“换个伙伴”选栗栗，切到重力模式，从高处拖起后松手：开伞时微笑，着地闭眼，起身时 ^ ^，站好后正常眨眼；在聊天中打招呼时会挥手。米露、页芽、小航落地时脚不应再在地面滑动。
