# GaryHub v1.4.3.0：订阅额度与个人背景音乐

|---|---:|---:|
| Ledger 固定开支 | 5 项 | 300 项 |
| Todo List 待办 | 5 条 | 300 条 |

| GaryHub 默认背景音乐 | 可用 | 可用 |

按保存总数计数：已完成的待办、停用的固定开支仍计入；删除后释放名额。普通账本收支记录不受这次固定开支额度影响。

已有超额数据不截断、不删除。可以编辑原内容、标记完成、排序或删除。仍超过新额度时不能新增或替换成新编号；原有超额 points 也只能整理原编号。降到额度以内后可在额度内新增。导入预览、确认导入、普通保存均由后端检查；角色与等级从事务内的当前用户记录读取，不信任浏览器传来的等级。

## 音乐体验

粒子页面唱片按钮旁新增音乐库入口，地址 `https://calendar.garyhub.uk/music/`。订阅用户和管理员可以上传 MP3、选择默认或自己的歌曲、删除自己的歌曲。选曲随账号保存；开关与播放位置继续在浏览器记忆，播放位置按账号和曲目区分。跨页面协调避免同时播放多个窗口。浏览器阻止自动播放时点击唱片开始。

普通用户只播放默认音乐。订阅降级后个人音乐播放与上传暂停，文件保留；仍允许删除自己的文件，重新订阅可恢复选择。账号切换、退出或禁用后，已打开页面在下一次焦点检查或至多约 10 秒的可见页面轮询中恢复默认曲目；已经签发的 R2 链接有效期为 5 分钟，不能用于访问其他文件。

R2 未配置或配置无效时，默认音乐仍可用，页面说明如何由管理员完成设置。网络故障或 MP3 解码失败时显示播放未成功状态，可重新选择默认音乐。格式检查验证 ID3 边界及连续 MPEG Layer III 帧，扩展名与 MIME 也必须符合；最终能否解码仍由浏览器决定。

## 存储与清理

MP3 上传一次经过服务器，读取到有大小上限的内存缓冲，然后写入私有 R2 桶；不写音频临时文件到服务器磁盘。单个 Calendar 进程同时接受一个上传，读取和对象操作设有超时，并保留 Origin、CSRF 与账号归属校验。无需新增生产 npm 依赖，也无需 FFmpeg。

播放时 GaryHub 仅返回短时签名 GET 链接，浏览器直接从 R2 获取音频。SQL 数据库保存歌名、大小、散列、对象键、选曲和清理任务，API 不返回密钥或其他账号的对象键；Tools/Homepage 仅代理只读选曲查询。所有个人数据接口保持 no-store。

在事务内预留曲目数和字节数。站点的应用管理音乐对象合计上限为 8 GiB，个人上限为 100 MiB / 10 首。上传中及尚未确认删除的对象仍计入配额。清理失败保留任务并重试；上传结果不确定的对象至少等待 15 分钟再清理，以避免仍在执行的 PUT 与 DELETE 竞态。中断遗留的上传预约在 15 分钟后转入清理。数据库迁移是追加表和触发器，不改动已有业务记录。

删除音乐或删除账号会把对象加入持久化删除队列，再清理存储；账号删除同时移除音乐偏好和在线元数据。删除触发器在回滚后的旧应用中也生效，但旧版本没有 R2 清理进程，遗留云对象会在再次运行本版本时继续清理。回滚不删除用户音乐，也不恢复旧数据库覆盖新记录。

应用的 8 GiB 限额不是 Cloudflare 账单硬上限：不包含人工上传到桶内的其他对象或诊断探针，读取请求等仍按 Cloudflare 计费。请使用独立音乐桶并查看其用量。

## 配置、安装与恢复

安装过程复用统一更新器，严格要求两个 Web 服务实际运行 v1.4.2.0；有/无 TOTP 两种能力组合分别检查原源码。保留有效 Compose、现有挂载、共享登录与所有 v1.4.2.0 的 Reading/监控配置；本次不修改 Caddy、Miniflux、PostgreSQL 或 VPN。

Calendar 新增只读挂载 `/etc/garyhub/music-r2.env` → `/run/garyhub-music.env`。首次安装只创建空的 0600 配置文件，不需要先提供 R2 密钥。完成 R2 网页设置后双击 `SETUP-R2.cmd`，输入 Account ID、桶名、Access Key ID 和隐藏输入的 Secret Access Key。通过现有 SSH 安全连接保存，验证真实对象写入/读取/删除；失败恢复原配置，不重启服务。存在音乐记录或待删除对象时，配置工具拒绝更换账号或桶，允许轮换同桶凭据。

安装现场继续执行离线 overlay 构建、合成账号隔离测试、SQLite/Lab 一致性备份、迁移干跑、切换、HTTPS/健康验证，最后向全部批准启用的账号（含管理员）发布未读通知并验证去重。`ROLLBACK.cmd` 回到 v1.4.2.0，保留当前记录、密钥与音乐元数据；后续部署或配置变化时停止覆盖。

具体 Cloudflare 操作见 [R2 配置指南](GARYHUB_V1_4_3_0_CLOUDFLARE.md)。测试与未验证边界见 [验证记录](GARYHUB_V1_4_3_0_TESTS.md)。源码已准备或本地测试通过不代表生产上线。
