# GaryHub v1.3.5.1 · 一次运行更新

适用于已经成功安装 v1.3.5.0 的 GaryHub。程序自动识别是否已安装 TOTP，保留原有可选功能。

## 你只需要完成这些操作

1. 将整个 ZIP 完整解压到一个新文件夹，不要直接在压缩包里运行。
2. 保存网站中正在编辑的内容，双击 **RUN-UPDATE.cmd**。
3. 若提示 SSH 私钥口令，输入原来的口令，等待 **8/8 COMPLETE GaryHub v1.3.5.1**，刷新页面。

无需复制应用代码、填写 API Key 或安装服务器依赖。沿用 Windows OpenSSH、现有服务器和 `%USERPROFILE%\.ssh\garyhub_interserver_ed25519`；严格核对已有主机密钥。口令输入不显示字符，私钥不会上传。

如出现 STOPPED，将末尾文字发回；不要跳过源码或备份检查。获得安装包不代表生产环境已经更新，成功以服务器的 COMPLETE、HTTPS 和通知验证结果为准。

## 本次五项功能

- **用户名或已验证邮箱登录**：使用同一个账号、密码和权限；未验证邮箱不可用于邮箱登录，用户名登录保留。存在身份匹配歧义时不猜测账号。
- **邮箱找回密码**：Calendar、Tools、首页和学习空间登录页均有“忘记密码”。输入用户名或已验证邮箱，验证码仅发到该账号原先绑定的邮箱，无需管理员审批。6位验证码10分钟有效，每次最多尝试5次，重发间隔60秒，并有账号和IP频率限制。验证后设置两次一致的10–128字符新密码，成功后撤销旧登录，再用新密码登录。未绑定、未验证或无法访问邮箱时，联系管理员走现有临时密码流程。
- **CAD / HKD**：新增加元和港元，记账、收入、退款、汇总、趋势及类别统计同步支持。保留原币金额；逐笔通过同一份最新参考报价折算并四舍五入到分。报价来自现有 Frankfurter 服务，注明各币种报价日期，不包含手续费；历史区间也使用当前显示的参考报价。缺少完整有效汇率时保留四种原币明细，暂停合并统计，恢复后自动继续。
- **统一导航**：日历、日记、健康、记账、待办清单页面都提供五项顶部导航，当前页面高亮。
- **明细15条与折叠**：收支明细每页最多15条，进入或刷新默认展开，可手动收起。同次浏览中筛选不改变展开状态；统计始终包括筛选范围全部记录。

保留已有中英文切换、日夜主题、手机布局、账号隔离和所有历史记录。

## 安装器自动完成

1. 核对包完整性、两个实际运行容器的 v1.3.5.0 标记、源码哈希、有效部署索引、挂载及已有邮件服务配置。
2. 基于当前实际镜像离线叠加代码，保留环境变量、共享 Cookie、网络、数据挂载和已有 TOTP 主密钥。
3. 在内部隔离网络、合成账号和捕获邮件目录中测试两项新服务，不向真实用户发送找回邮件。
4. 创建并核对 SQLite 一致性备份、Lab 文件逐字节备份；在真实数据库的独立副本上演练币种迁移，逐字段验证历史明细及退款关联没有变化。
5. 切换 Calendar 与 Tools/Lab，检查应用健康。
6. 核对正式 HTTPS、登录恢复资源、四币种界面、五项导航与私人接口认证。
7. 向本次已批准且启用的账号（含管理员）发布未读站内更新通知，并验证重复执行不会重复通知。
8. 保存上线记录，尝试在干净、来源与基线匹配的本地仓库建立更新分支并提交源码。

两项 Web 服务切换时短暂不可用。提醒 worker、Xray、授权同步器、Files、RSS 和监控沿用原有部署。数据迁移不删除或改写原账目金额。

如果只有通知失败，状态为 notification-pending；再次运行同一入口只重试通知。完整成功后重跑不会重复部署或迁移。线上源码与已审阅基线不一致时会在切换前停止，不覆盖未知改动。

## 源码与 GitHub

源代码、测试与说明保存在 `%LOCALAPPDATA%\GaryHub\updates\v1.3.5.1-r1`。
本地仓库默认 `D:\Codes\Own_Project\garyhub-repo`。符合条件时建立 `update/garyhub-v1.3.5.1` 分支并提交，不覆盖已有改动。

安装完成后，可双击 **PUSH-TO-GITHUB.cmd** 推送准备好的分支，再在 GitHub 创建和合并 PR。推送和合并不会自动修改服务器。源码同步警告不等于服务器更新失败。

## 回滚与恢复

**ROLLBACK.cmd** 检查当前镜像及部署索引后，恢复更新前镜像，保留当前数据。若后续已升级或修改配置，会停止以保护后续工作。

**已经写入 CAD 或 HKD 账目时，自动回滚会停止**：v1.3.5.0 无法正确读取这些币种，不能为了降级而删除或修改真实账目。应保留当前版本并联系维护者处理。普通回滚不会用历史数据库覆盖上线后的新记录。

成功回到旧版后，旧版不提供邮箱找回；新增恢复表保留，旧版的账号删除保护可能暂停删除操作，需要重新安装本版后操作。有进行中的账号删除时也暂停降级。

服务器运行记录：`/opt/garyhub-update-v1.3.5.1-r1/deployment-state.json`；有效部署以 `/opt/my-services/garyhub-active-deployment.json` 为准。同目录 private-backup 含正式数据库、配置及可能的 TOTP 主密钥，仅保留在受限服务器备份中，不上传聊天或 Git。
