# GaryHub v1.4.1.0 — Research Dictionary

基础版本：两服务均实际部署 v1.4.0.1。审阅源码：`637d86faae37d6c06b74b15bf850e82e301c8ad7`（main，PR #18）。本次只准备升级包；是否安装成功以服务器现场证据为准。

## 使用

Tools 新增「科研词典 / Research Dictionary」，指向 `https://calendar.garyhub.uk/research/`，复用 GaryHub 账号。每个账号的 Research 和术语独立；管理员也不能浏览其他账号的词库。本版没有团队共享或模型 API 调用。

1. 顶部第一行：切换 Research、新建、项目设置（名称与研究简介）。
2. 第二行：中英文搜索、下载 Prompt、导入、导出、新增词条。
3. 下方约 30% / 70% 双栏：左侧标签与词条列表，右侧完整释义、用法和双语例句。分隔线支持拖动或方向键。手机切换列表和详情，保留返回按钮。
4. 选择词条后点「编辑词条」，可以修改任何词对、别名、首选表达、释义、用法、例句、标签、来源及核对状态。每行一个表达，第一行为首选。中英文任一表达与别名都能搜索；多标签按同时满足筛选。

## AI 与导入

先填写研究简介，再下载包含当前项目上下文的 Prompt，连同论文/README 资料交给外部 AI，导入返回的 JSON。导入窗口支持文件选择、粘贴和下载示例。文件格式为 `garyhub-research-v1`；规范实现在 `calendar-app/public/research/format.js`。Prompt 不要求 AI 填写 ID；每条释义含英文/中文数组、释义、用法、1–2 组英文例句及中文翻译、标签、来源和核对状态。

每个账号最多 50 个 Research；每个 Research 最多 1,000 条释义、3 MB 词库；每种语言最多 12 个表达，每条最多 12 个标签。释义/用法各最多 4,000 字符，每句英文及译文各最多 2,000 字符。导入和编辑都在服务端验证。站点不验证例句的学术事实，需要人工核对。

- 完全重复：跳过；相同含义、同一组中英文关联且无冲突：补充去重。
- 相同中/英文、释义差异、多候选或已有人工修改：先预览，选择跳过、新增独立释义、合并补充或替换。
- 合并保留原释义、已有用法与来源，只补充别名、译法、标签、例句和空白字段。例句合计超过两组时不能直接合并，可选替换或新增。导入改变词条后状态为待核对。
- 替换保留已有词条 ID，明确替换该释义的内容；新增始终生成目标词库自己的 ID。只有本站导出文件的 Research ID 与目标相同，词条 ID 才用于定位更新。
- 预览不写数据。所有冲突处理完且再次预览后才允许确认。多义候选过多时最多展示前 20 项，可跳过后在词库定位编辑；后台仍核对完整候选集。
- 可撤销最近一次导入；之后如有编辑或另一项写入，旧撤销失效，防止覆盖后续工作。导入重试通过请求编号去重。
- 保存以 Research 修订号检查并发；账号发生变化、禁用或会话失效时拒绝写入。失败时保留页面输入，不自动覆盖其他页面的更新。

数据为 Calendar SQLite 的新增关联表 `research_projects`、`research_receipts`，沿用现有数据挂载、备份与账号删除流程；迁移不改写旧事项等记录。

## 安装、回滚与源码

完整解压 `GaryHub-v1.4.1.0-Upgrade.zip`，双击 `RUN-UPDATE.cmd`，输入现有 SSH 密钥口令。不要在 ZIP 内直接运行，不需要旧升级包，也不需要在线安装应用依赖。

安装器复用统一入口与共享部署运行时：核对实际基础版本、两种能力组合及源码 → 离线镜像构建 → 隔离数据测试 → 一致性备份 → 切换 → HTTPS 与精确资源字节验证 → 所有启用账号的未读站内通知与幂等核验。通知失败保留可重试状态；未完成不能报告全部成功。成功给出摘要，失败查看末尾 STOPPED 和私有日志。

`ROLLBACK.cmd` 恢复 v1.4.0.1 应用镜像，保留当前数据库与新增 Research 记录，不恢复旧数据库。旧界面不显示词库，重新升级后仍可使用。旧账号删除器遇到新增关联表可能要求审阅；不要绕过其安全检查。回滚拒绝覆盖后续部署。

`PUSH-TO-GITHUB.cmd` 在独立 worktree 导入源码并推送审查分支 `update/garyhub-v1.4.1.0`，保留原工作区，不 force push、不自动合并 main。安装器只自动准备本地源码，是否推送由维护者决定。

详见 `docs/GARYHUB_V1_4_1_0_TESTS.md`。本地验证、GitHub 合并、生产验证是不同状态；本次未连接正式服务器。
