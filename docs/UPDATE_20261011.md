## 发布流程

`deploy.py` 校验采集时的镜像、修改文件哈希、挂载及主页哈希；从运行镜像构建覆盖层，保留 Access 模块、Pyodide 和运行依赖；先在独立网络及测试数据上跑完整 smoke 检查，再备份和切换。

变更两个 Web 容器和 Caddy 主页路由。提醒 worker、Xray、网络授权同步器、Files、RSS、监控服务不参与本次镜像切换。新增的数据库结构向后兼容，提醒 worker 原有查询不受影响。

正式部署期间 Calendar 与 Lab 有短暂中断。失败时恢复旧镜像与 Caddy，不用旧数据库覆盖用户的新数据。手动回滚先核对配置和镜像未被后续更新修改。

完成后用 `calendar-app/releases/garyhub-20261011-v1.json` 向所有启用用户发布四条分类更新；幂等去重，Homepage 汇总展示。此后每次更新必须遵循 `RELEASE_POLICY.md`。
