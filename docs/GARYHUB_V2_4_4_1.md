# GaryHub v2.4.4.1 · 个人网站导航的文件选择修复

发布日期为 2026-11-27（America/Chicago）。安装器 v2.4.4.1-r1 从两服务均运行 v2.4.4.0 的环境升级。本版基于 PR #56 的合并提交 `1aa5eca38991db74cc8c648b8e44386eb785858f`，该提交与 v2.4.4.0 交付源码的树完全一致。

## 选好文件后如何判断

在 Tools → 个人网站导航 → 添加网站中选择 HTML、ZIP 或网站文件夹。页面会显示「已选择」及实际文件名，下面的「入口文件」列出可以打开的 HTML。可以提前填写网站名称，也可使用网页标题。确认入口后，「只打开一次」或「保存并打开」按钮才会启用。

如果浏览器拒绝带授权的选择器、关闭了系统窗口或一直没有返回选择，面板会提供「普通文件选择」。直接在这里选择同一个 HTML、ZIP 或目录即可重试。用这种方式保存书签时，页面会提示下次需要重新选择本机文件。支持持续授权的浏览器仍可通过原文件句柄直接重开。两种方式都在本机读取内容，书签和授权提醒沿用原来的账号机制。

## 修复内容

- v2.4.4.0 在尚未拿到文件时也允许提交。取消选择可能没有反馈，保存操作还会覆盖先前的权限或读取错误。新版在读取期间锁定提交，并在弹窗内提供可直接操作的普通选择器。
- 只在读取到有效入口后接纳新的选择。取消、空文件夹或缺少 HTML 时保留具体提示和上一次有效选择。迟到的选择结果不能覆盖后来选好的文件。
- 文件夹选择同时支持带根目录名与直接从网站根开始的相对路径。直接返回 `index.html` 和 `assets/…` 时，首页文件名会完整保留。目录信息缺失时会提示选择 ZIP 或单个 HTML。
- 私人书签、已授权文件、通知中心与重新授权机制均沿用 v2.4.4.0。无需新增数据库表、运行依赖、DNS 或 Caddy 配置。

## 安装

在原维护电脑上完整解压 ZIP，在包目录双击 `RUN-UPDATE.cmd`。等待 `8/8 COMPLETE GaryHub v2.4.4.1`，回到 Tools 刷新个人网站导航。需要回滚应用时双击 `ROLLBACK.cmd`。包内 `PUSH-TO-GITHUB.cmd` 可单独用来准备源码审查分支。生产状态与通知接收人数以实际安装日志为准。
