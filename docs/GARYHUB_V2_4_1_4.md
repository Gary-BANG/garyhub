# GaryHub v2.4.1.4 · 设置中心

源码基于 main `5306dd9b56d753b4b7fd99a92400196b392fe6f8`（PR #46 合并的 v2.4.1.3），独立分支 `update/garyhub-v2.4.1.4`。安装器 v2.4.1.4-r1 严格要求两服务实际运行 **v2.4.1.3**（2026-11-17 tools 与 calendar 的 `/health` 均返回 2.4.1.3）。源码已准备、本地验证；尚未推送、合并或部署。

## 为什么做

原来的“个性化”页只有学习中心的三项。其他偏好散在各处，大多只存在某个浏览器里：

- **日夜主题**：有三套互不相通的开关，而且按子域名分开保存。
- **网站伙伴**：设置存在 Cookie 里。
- **账本币种与工具台布局**：存在 localStorage。
- **时区**：放在 Calendar 首页。

换设备或换子站，这些选择就丢了。维护者 2026-11-17 选定先做设置中心，并要求保留各页面上的日夜切换按钮。

## 设置中心（`tools.garyhub.uk/personalize/`）

右上角的头像图标改名为“设置”。页面分六节，每一项改动后立即保存，并显示“已保存”或失败原因。

| 分节 | 内容 | 保存位置 |
|---|---|---|
| 外观 | 日夜主题（跟随系统／浅色／深色）；主页星空（完整／安静／静止） | 账号偏好 |
| 语言与地区 | 界面语言；时区（可一键使用本设备时区） | 语言：账号偏好；时区：原有的 `users.timezone` |
| 网站伙伴 | 角色（按账号等级可选）；主页与工具台默认展开或收起；其他页面默认展开或收起；重力模式；是否显示 | 账号偏好 |
| 学习中心 | 阅读外观、正文字号、标题字号，新增行距（1.4–2.5）和正文宽度（600–1400 px），带实时预览 | 学习中心自己的记录（不变） |
| 记账与工具台 | 记账默认币种；工具台布局（多行图标或单行 Dock） | 账号偏好 |
| 通知与订阅 | 链接到 Calendar“账号与提醒设置”（日历订阅、推送、邮件提醒），从这里打开会自动展开那一节 | 不变 |

## 日夜切换

- **一个设置管全站**：Tools、Calendar、A 股、本地工具、登录页共用同一个日夜设置。
- **页面按钮保留**：每页右上角的 ◐ 按钮照常可用，切换浅色或深色后，全站一起变化，并保存到账号。
- **跨子站与首屏**：选择同时写进 `.garyhub.uk` 下的 Cookie `garyhub_prefs`，子站之间立即一致，页面第一次绘制前就用对颜色。
- **例外**：主页与开发者页固定为星空深色；学习中心的阅读外观仍独立。

## 实现

- **Calendar `preferences-api.js`**：
  - **表与接口**：新表 `user_preferences`，每个账号一行，无外键，已加入账号删除清单。接口为 `GET`／`PUT /api/hub/preferences`。
  - **校验**：10 个键，每个键只接受固定取值，`null` 表示恢复默认。
  - **原子写入**：用一条 `json_patch` 语句写入，同时保存不同的键不会互相覆盖。
  - **时区**：写 `users.timezone`，按 IANA 名称校验。
  - **安全检查**：账号不一致返回 409；沿用 Origin 与 CSRF 检查；每个地址每分钟最多 120 次。
  - **接线**：经 `extras.js` 注册，`app.js` 只改了版本号。
- **Tools/Lab `server.cjs`**：把 `/api/hub/preferences` 加入现有的账号代理路由；主页主机允许提供 `/hub-prefs.js`。无 TOTP 组合的覆盖文件做了相同改动。
- **共享 `hub-prefs.js`**（两服务各一份相同副本，除外站页和 Lab 登录跳转页外，所有页面都在 `<head>` 中尽早加载）：
  - **共享日夜**：提供 `GaryHubTheme`，各页面原有的切换函数改为调用它。
  - **账号优先**：登录后读取账号偏好，写入各页面原本读取的 Cookie 和 localStorage。
  - **一次性迁移**：账号还没有、而本浏览器已有的选择，会上传一次，旧设置不会丢。迁移完成的标记写在共享 Cookie 里，之后不再读取旧键。
  - **回写**：伙伴面板、语言按钮、记账和工具台布局的改动会保存回账号。访客只在浏览器里保存。
- **页面改动**：
  - `theme.js`、`ambient.js`、`research.js`、`hub.js`、`stocks/app.js`、`useful/tool-shell.js` 的日夜逻辑改用共享设置。
  - `cosmos.js` 支持“安静”和“静止”星空。
  - `companion/boot.js` 保存设置时发出事件，两份副本相同。
  - `ledger.js` 与 `fixed.js` 等账号偏好载入后再取默认币种。
  - `tools-dock.js` 跟随账号布局。
- **学习中心接口**：`academic.cjs` 的阅读偏好接口增加行距和正文宽度，并校验范围。旧客户端可以不传这两项。

## 兼容与回滚

- **新表**：只有 `user_preferences` 一张，以 `IF NOT EXISTS` 创建，无外键。回滚到 v2.4.1.3 时保留但不再使用；旧版的账号删除检查不会被它阻塞，只是旧版删除账号时这张表里的记录不会一起删除。
- **浏览器缓存**：回滚后旧页面仍读各自的旧 localStorage 键，浏览器里的日夜选择可能回到升级前的值，账号数据不受影响。
- **无其他变化**：没有新依赖，Caddy、Compose 和环境变量都不变。
