## 权限、回归与安装边界

有 TOTP 和无 TOTP 两种应用组合各启动真实 Calendar 和 Tools/Lab 进程，各自使用独立的本地合成数据库，分别运行十组 HTTP 检查。股票检查覆盖订阅、未登录与普通账户、跨账号写入、CSRF、Origin、每人 3×5、同股重复、并发冲突、新接口及已登录股票页面/脚本/样式哈希。其余九组覆盖现有工具、学习中心、资源响应、音乐、伙伴、外站、助手、通知和答疑。旧伙伴测试读取路径在本机由 APP_DIR 映射，Docker 安装检查继续使用 /app。

每种组合均向 5 个合成账号发布一次更新通知，复跑核对去重，SQLite 外键检查通过。Windows 安装、服务器有效 Compose、离线 Docker 切换与回滚、生产通知人数需以现场日志确认。应用当前为本地准备状态。

## 浏览器与更新器

在 Chromium 中用合成订阅账号通过实际页面和后端测试，分别检查 390×844 与 1280×900 视口。检索“同花顺”只发送目录查询，点选后只查报价，打开盘口未增加网络请求；分时、日 K 和财报各在首次展开时读取。验证了 5 档买卖、通过方向键读取交易日及 MA20、选择不同报告期、分组创建/收藏/删除、刷新后收藏保留及临时详情清除。两个宽度没有横向溢出，页面无脚本异常。这是浏览器视口测试，未在实体 iPhone 上运行。

统一版本清单通过检查；共享更新器测试 35 项通过，2 项因缺少 PowerShell 环境跳过。部署及回滚继续要求现场基线、备份、HTTPS、源码校验等保护。
