# GaryHub v2.3.1.1

日期：2026-11-05（America/Chicago）。基线 main ea6a6d8acf7fc716a6de15d3c21afb165faa6e3c（PR #33 已合并 v2.3.1.0）。

完整解压后双击 RUN-UPDATE.cmd；严格要求两服务运行 v2.3.1.0。ROLLBACK.cmd 恢复 v2.3.1.0 应用、保留当前数据；PUSH-TO-GITHUB.cmd 使用独立工作目录和审查分支。复用共享更新器与 9 项隔离检查，安装时仍执行备份、HTTPS/资源校验和全体启用账号的未读更新通知及去重。
