# 验证记录 · GaryHub v1.3.4.0

基线：GitHub main 提交 feb1d823a24064eb814134e6b4b8395e32062283。
开发环境：Node 24.19.0，Express 4，express-session，原生 sqlite3 6.0.1（SQLite 3.52.0）；真实 HTTP 服务联合运行。没有使用用户的真实数据库、账号密码、SSH 私钥或邮件授权令牌。

## 已通过

- 79 项核心 HTTP 断言：共享账号登录、路人会话、首页解锁、错误码拒绝、保护开关、修改访问码、撤销已有授权、Admin 访客预览、原 GPA/Rank 指定用户权限保留、匿名 CSRF Cookie 经代理转发、受保护 HTML 与 JSON 不公开、现有日记接口仍工作。
- 记账：本人读写隔离、管理员不能指定他人账目、跨账号草稿拒绝、CSRF/Origin 拒绝、币种隔离、类别过滤、日期合法性、含首尾和零消费日的平均数、收入/退款/净支出、重复创建去重、旧修订拒绝、关联退款约束、类别停用。
- 额外集成检查：并发退款不能超过原消费，删除退款后可删除原消费，32 笔小额金额的整数分精确汇总，30/2 分页记录无重复。
- Chromium 浏览器实际操作：1440px 桌面、390px 手机，日夜模式，保存一笔消费、添加类别、移动端无横向溢出，访客解锁与重新隐藏，Admin 输入访问码时定时身份刷新不会清空草稿，Admin 访客预览。测试中无 JavaScript 页面错误。已检查页面截图。
- 站内通知发布：3 个已启用合成账号各收到 Homepage/Calendar 两类通知；再次执行发布不重复创建，核对收件人数一致。
- 6 项部署辅助测试：仅替换首页 Caddy 块，正确处理注释/引号内的大括号，未知配置拒绝，一致性 SQLite 备份与拒绝覆盖，Lab 备份逐文件校验，应用回滚保留数据库内容。
- 所有新增/修改 JavaScript 的语法检查及部署 Python 编译检查。
