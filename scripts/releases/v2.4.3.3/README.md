# GaryHub v2.4.3.3 · 大富翁：交易、拍卖与胜负方式

源码基于 main `731e8bcac1935c2f45e496d085fa8cc571d35304`（PR #53 合并的 v2.4.3.2），独立分支 `update/garyhub-v2.4.3.3`。本版尚未部署服务器。

## 本版内容

- **胜负方式**：限定回合（原有）；经典——玩到只剩一人，第 25 回合起每 10 回合过路费加基础的一半，第 100 回合按总资产保险结算；限时——30／60／90 分钟，到时打完当前回合，房间暂停时顺延。
- **交易与还价**：轮到你时向任何玩家提议换地和现金（一方出钱，有房色组不能交易），对方接受、拒绝或还价（最多 3 次）；电脑为凑齐一组主动提议（现金或互换），按价值接受或还价；托管不交易。
- **拍卖**：没人买的地轮流加价（至少 100，以现金为限），放弃即退出，最高出价者买下；电脑按上限竞价，托管直接放弃。
- **电脑**：每个决定在记录里写理由；盖房优先对手下一掷最可能踩中的色组。
- **页面**：格子序号，记录写作“#序号 名称”并按回合分段；动画按服务器事件顺序播放，速度可选慢速／正常／2 倍速／迅速（两款棋盘游戏通用）；金币飞动、翻牌、资产走势图；交易与拍卖面板在棋盘下方，手机上在底部抽屉。

旧房间（不带新设置）与 v2.4.3.2 存下的对局保持原规则。没有新表、没有新依赖，Compose、环境变量与 Caddy 均不变；`app.js` 与 `server.cjs` 只改版本号。

详细说明见 `docs/GARYHUB_V2_4_3_3.md`。

## 安装、回滚与源码

完整解压 `GaryHub_v2.4.3.3_upgrade.zip`，在 Windows 双击 `RUN-UPDATE.cmd`。两服务必须实际运行 **v2.4.3.2**（2026-11-21 生产 `/health` 已返回 2.4.3.2）。

- **核对链**：`deploy.py` 以 `prior_0432.py` 载入 v2.4.3.2 适配器（再到 v2.4.3.1、v2.4.3.0…），沿用其全部核对。
- **Caddy**：第 1 阶段只读核对 `games.garyhub.uk` 站点块仍在；不写入、不恢复。
- **第 6 阶段新增核对**：两个运行容器中的本版文件（`play-monopoly.js` 的拍卖、`play-rooms.js` 的暂停顺延、本版通知；Lab 的 `monopoly.js`、`board.js` 的速度控件、`play.js` 的设置）；游戏资源哈希组的文件列表不变、内容哈希更新。
- **隔离检查**：十九组，新增 `tycoon-http.cjs`。
- **站内通知**：一条（home）。

`ROLLBACK.cmd` 恢复 v2.4.3.2，保留当前记录与设置；回滚后正在拍卖或等待交易回复的大富翁对局会卡住，需要离开房间。`PUSH-TO-GITHUB.cmd` 只推审查分支，不合并 main。

构建：`python scripts/updater/manage.py build --release 2.4.3.3 --output <ZIP绝对路径>`。验证范围见 [TEST-RESULTS.md](TEST-RESULTS.md)。
