## 规则

- **胜负方式**：限定回合；经典（只剩一人；第 25 回合起每 10 回合过路费加基础的一半——没有这条时电脑对局 20 局有 18 局打到 100 回合；第 100 回合保险结算）；限时 30／60／90 分钟（到时打完当前回合，暂停顺延）。
- **交易**：轮到你时提议换地和现金（一方出钱，有房色组不能交易，每方 ≤6 块，每回合 ≤3 次）；对方接受、拒绝或还价（≤3 次）；接受时复核；超时视为拒绝。
- **拍卖**：不买的地轮流加价（≥100，以现金为限），放弃即退出，最高者买下，没人出价留给银行。
- **兼容**：新设置缺省等于旧规则；旧房间、v2.4.3.2 存档、上一版 `boards-http` 都按旧规则运行。

## 电脑

- 只差一块（精明一到两块）时向持有人提议：现金（1.5／1.3 倍）或互换；被拒 3 回合内不再提。按“凑齐 ×2.5、送对方凑齐 ×2／×2.5”估值，精明不单方面送组，差额还价。
- 拍卖按上限竞价；盖房优先对手下一掷最可能踩中的色组。
- 每个决定在记录写理由，只在电脑行动时保存（`play-rooms.js` 传 `ctx.bot`）；托管（`bot(…, {auto})`）不交易、不竞拍。

## 页面

- 格子序号，记录写“#序号 名称”并按回合分段。
- 动画按服务器的事件列表顺序播放（掷骰、走棋、金币、翻牌、交易），积压时加快；速度可选慢速／正常／2 倍速／迅速（`board.js`，存本机，两款棋盘游戏通用）；电脑与下一位的计时都等动画（≤3 秒）。
