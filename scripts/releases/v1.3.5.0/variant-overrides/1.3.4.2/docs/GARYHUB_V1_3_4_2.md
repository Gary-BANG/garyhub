# GaryHub v1.3.4.2

开发分支：`update/garyhub-v1.3.4.2`。适用于已经成功部署 v1.3.4.1 的服务器。下载更新包不代表已经上线；真实构建、备份、HTTPS 和通知结果以安装器现场输出为准。

## 一次完成升级

1. 将 `GaryHub_v1.3.4.2_Update.zip` 完整解压到新文件夹。
2. 双击 **RUN-UPDATE.cmd**；如有提示，在本机输入已有 SSH 私钥口令。
3. 等待 **8/8 COMPLETE GaryHub v1.3.4.2**，再刷新 Tools 和首页。

当前安装器为 **r2 修正版**，产品版本仍为 v1.3.4.2。如果首包停在 `garyhub-lab/public/index.html` 源码核对阶段，直接将本包解压到新文件夹，再双击运行即可，无需删缓存或回滚。r2 使用独立的本机与服务器目录，保留首包的核对记录。

修正原因：10 月 14 日 Academic 安装器为线上首页加入两张卡片，同时将工具数量从 06 改为 08；仓库保留了 06。v1.3.4.0、v1.3.4.1 都沿用该镜像文件，首包只接受仓库校验值，因而拒绝合法的线上版本。r2 从历史包重建并核对 v1.3.3.2 明确支持的两种首页，增加这些文件的精确校验值；未知修改仍停止。历史来源与公开测试样本保存在 `scripts/releases/v1.3.4.2/reviewed-runtime-baselines.json` 和 `tests/fixtures/`，本地 Git 源码核对仍只接受 Git 基线。

程序沿用现有 SSH 密钥、服务器、账号、Session、网络与数据挂载；自动核对源码及当前有效部署索引，在当前镜像上离线构建，进行隔离测试，生成并妥善保存 TOTP 加密主密钥，备份数据库与 Lab 文件，切换 Calendar 和 Tools/Lab，检查 HTTPS，并发布未读站内通知。提醒 worker 和网络节点不参与镜像切换。

入口：`https://tools.garyhub.uk/totp/`。账号等级与资料规则：`https://tools.garyhub.uk/admin/`。

## 2FA 验证码

- 支持 RFC 6238 的 SHA-1、6 位、30 秒 TOTP；输入 Base32 密钥，允许空格及小写。名称为 1–80 字符。当前每账号最多 50 项、全站最多 500 项，每页展示 18 项。
- 普通用户与订阅用户可以添加、改名、删除自己的条目；本人提交后也没有查询原文、导出或生成密钥二维码的接口。
- 管理员可查看所有条目的原文，必须主动点击“查看密钥”，页面 30 秒后自动隐藏，关闭或切走页面也会隐藏。管理员对其他人的条目只增加查看、使用和授权权限；改名、删除仍属于条目所有者。
- 管理员可授权给已批准且启用的账号，支持 30 分钟、1/2/12 小时、1/7 天和自定义带时区的截止时间。可调整期限或立即撤销，同一条目与接收人保持一份授权。
- 普通用户、订阅用户及被授权人不能转授权。订阅身份不会自动授予别人的验证码。
- 每次请求检查当前账号、角色、所有者启用状态及授权截止时间。到期无需定时任务即可拒绝接口访问。代码响应包含服务器时间和本轮截止时间，前端不使用本机墙上时钟计算验证码。
- 页面每 5 秒重新取当前页验证码并复核授权；过期、隐藏页面、账号变化或请求失败时清除显示。已经看到的数字仍可能在原网站的时间窗口内有效。
- 删除条目同时删除全部授权；这不修改原网站的 2FA 配置。

## 加密与备份

`GARYHUB_TOTP_ENCRYPTION_KEY` 是 32 个随机字节的规范 Base64 值，独立于 Session Secret。安装器在服务器生成，写入受限环境配置，并保存到 `/opt/my-services/private/garyhub-totp.env`（目录 0700、文件 0600）。不会要求用户复制填写，也不会输出其值。

密钥原文用 AES-256-GCM 加密后入库，每项采用独立随机 nonce，附加认证数据绑定条目 ID 与所有者 ID。数据库只保存密文、nonce、认证标签和加密密钥编号。修改绑定信息或使用错误主密钥无法解密；配置缺失时返回服务不可用，不回退到明文。

升级目录的 `private-backup/timestamp/` 同时保存一致性的数据库副本及 `totp-key.env`。**数据库和加密主密钥必须共同备份，主密钥仅限受控备份，不上传 Git 或聊天。**主密钥丢失不能通过密文恢复。不得随意重生主密钥；有现存密文但密钥缺失或不匹配时安装器停止。日常恢复时也应恢复匹配主密钥，再验证一个测试条目。

不向浏览器下发加密主密钥或密文。敏感接口沿用 Session、Origin 白名单、CSRF，增加账号及 IP 限流并禁止缓存。审计只有账号/条目/目标编号、动作、时间；验证码查看按同一账号、条目和 30 秒周期合并，不保存名称、密钥、验证码或请求体。

## 三档首页资料保护

访问身份为路人、普通用户、订阅用户；管理员角色另行保存，并始终有完整查看权限。`users.account_tier` 为 `standard` 或 `subscriber`，注册和管理员新建账号默认普通用户。只有管理员可修改等级，接口使用版本比较防止并发覆盖。

初次升级精确匹配已有 `Gary_BANG`、`zhouyoyo` 账号并设为订阅用户，不改管理员角色、不创建新账号。迁移标记使此操作只执行一次；之后管理员取消订阅，不会因重启重新获得。安装前找不到这两个精确用户名时停止，等待核对。

三类各有保护开关、五组默认可见资料、访问码、24 小时解锁授权、撤销与预览。订阅用户的初始规则复制普通用户现有规则；原有路人和普通用户设置及单独 GPA/Rank 授权保留。更新某一类只撤销该类解锁。升级/降级后按新类别重新判断，旧解锁状态绑定账号及等级版本，不能跨类别使用。

这里只控制首页资料。日记、健康、账目和学习数据仍按原所有者隔离；网络节点授权与账号等级、资料访问及 TOTP 授权相互独立。本次没有支付或自动续费功能。

## 账号删除

接入 v1.3.4.1 的分阶段流程。删除开始时停用账号、失效 Session、取消订阅身份，并删除其收到的授权及本人条目授予别人的授权；等待网络撤销确认后，在数据清理事务中删除本人 TOTP 条目、关联授权和原有在线数据。删除预览显示 TOTP 条目与收到的授权数量。其它用户条目、审计编号及既有受限备份保留。

## 发布、源码与恢复

- 以 `/opt/my-services/garyhub-active-deployment.json` 及当前容器实际镜像、Compose 标签为准。索引不匹配、源码有其它改动或挂载异常时停止，不能跳过校验。
- 发布文件 `calendar-app/releases/garyhub-1.3.4.2.json` 包含 `home`、`tools` 两类说明。切换与健康检查通过后，执行现有通知程序，并重复执行验证去重。只向本次发布时已启用账号创建未读通知，包括管理员，不补发后来注册账号、不重置已读状态。通知失败标记 `notification-pending`，重跑同一安装器只重试通知。
- 安装完成后自动尝试在干净且匹配基线的 `D:\Codes\Own_Project\garyhub-repo` 创建并提交 `update/garyhub-v1.3.4.2`。本地同步失败不会覆盖现有工作，源码与测试保留在 `%LOCALAPPDATA%\GaryHub\updates\v1.3.4.2-r2`。
- 双击 **PUSH-TO-GITHUB.cmd** 可推送本地分支并打开 PR 比较页面。推送不自动合并、不自动部署。
- **ROLLBACK.cmd** 恢复旧镜像及部署索引，保留当前数据库、已新增记录和服务器加密主密钥。核对当前镜像和索引，避免覆盖后续更新。有未完成删除或临时密码流程时暂停降级。
- 旧版不提供 TOTP，也不识别新的账号关联表；回滚后其保护性检查可能暂停账号删除，应重新安装本版后操作。旧版首页按锁定兼容规则运行，需在其管理页重新配置。回滚不恢复已删除账号，不覆盖数据库；完整历史恢复另行处理。
- 运行记录位于 `/opt/garyhub-update-v1.3.4.2-r2/deployment-state.json`，私密配置、日志及备份不能提交 Git。重复运行同一成功包不重复迁移、部署或通知。源码不匹配时一并列出已核对文件的所有差异和校验值，不打印源码或私密配置。

本更新不包含真实数据库、用户密钥、服务器私钥或生产环境变量。更新包内开发验证见 `TEST-RESULTS.md`，仓库中对应 `docs/GARYHUB_V1_3_4_2_TESTS.md`。
