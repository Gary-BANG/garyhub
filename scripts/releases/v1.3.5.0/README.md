# GaryHub v1.3.5.0 · 中英切换、资料隐藏与 Todo List

适用于已经成功部署 v1.3.4.1 或 v1.3.4.2 的服务器。安装器会根据两个实际运行容器的发布标记选择对应源码，不安装或移除另一版本的可选功能。

## 一次运行

1. 完整解压 `GaryHub_v1.3.5.0_Update.zip` 到新文件夹。
2. 双击 `RUN-UPDATE.cmd`；提示时输入原有 SSH 私钥口令。
3. 等待 `8/8 COMPLETE GaryHub v1.3.5.0`，刷新网站。

不需要复制应用代码、填写新密钥或安装服务器依赖。程序使用原 Windows OpenSSH、原服务器及 `%USERPROFILE%\.ssh\garyhub_interserver_ed25519`。严格核对已有主机密钥。私钥及口令不会上传或写入包中。

## 本次功能

- 首页、Tools、Calendar、登录与注册、账号管理、日记、健康、记账、Grade Planner、Study Hub、Network Access，以及已安装的 TOTP 页面加入中文 / English 切换。浏览器记住选择，GaryHub 自有子域共用语言偏好。界面控件、提示与确认框跟随语言，用户输入的正文、标题、备注、课程名称和讲义原文保持原样。
- ECE 470 Lab 内部页面、Files、Reading、Status 保持原有行为。Tools 导航页支持切换。
- 首页未授权区域统一显示“该部分已隐藏 / This section is hidden.”，包括 GPA/Rank 的标题与字段名称。已授权用户仍按原有权限查看内容；分组规则没有合并或扩大。隐藏的项目入口只在有对应查看权限时显示。
- Calendar 原“日记与健康记录”区域增加 Todo List 卡片，入口为 `https://calendar.garyhub.uk/todos/`。
- Todo 没有截止日期，不自动创建日历事项或邮件提醒。每条可添加子要点、编辑、删除、勾选完成。主待办与子要点独立勾选。
- 拖动左侧手柄排序，手机也可拖动；可用手柄上的上下方向键或上下移按钮。顺序保存到账号，换设备后继续使用。
- 子要点每次打开页面默认收起，单独展开或收起。刷新后再次收起；展开状态不参与云端排序和内容保存。
- 自动保存完成时显示“已保存到服务器”。每账号最多 300 条 Todo、每条最多 100 个 point；标题最多 160 字符，point 最多 1,000 字符，总内容约 1.8 MB。
- 保存核对当前账号和修订号，多页面冲突会暂停覆盖，可先下载草稿，再重新加载。切换语言不清空正在输入的 point。
- Todo 只属于本人。管理员查看其他人的日历事项，不会获得其 Todo。账号删除流程包含 Todo 清理，保留其他用户数据。

## 自动更新流程

核对包、源码、部署索引与挂载 → 基于当前镜像离线构建 → 内部隔离网络上的合成账号联调 → SQLite 一致性备份与 Lab 文件逐字节校验 → 切换 Calendar 与 Tools/Lab → HTTPS 和隐私检查 → 给全部已批准启用账号（含管理员）发布未读站内通知，并核对重试去重 → 尝试本地源码提交。

两项 Web 服务切换时会短暂不可用，更新前保存正在编辑的内容。提醒 worker、Xray、网络授权同步器、Files、RSS 和监控的镜像或配置不参与切换。数据挂载、环境变量及已有 TOTP 加密主密钥保留。已安装 TOTP 的数据库与匹配主密钥共同保存到受限备份。

当前部署以 `/opt/my-services/garyhub-active-deployment.json` 和容器实际 Compose 标签为准。源码、版本或索引不匹配时，安装器在切换前停止；不要跳过检查。把末尾 `STOPPED` 输出发回即可核对，无需发送任何私密文件。

## 源码、重试与回滚

源码和测试保留在 `%LOCALAPPDATA%\GaryHub\updates\v1.3.5.0-r1`。若 `D:\Codes\Own_Project\garyhub-repo` 干净、来源正确且匹配已审阅基线，则自动创建并提交 `update/garyhub-v1.3.5.0`。已有改动不覆盖；源码同步警告不表示已完成的服务器更新失败。

需要同步 GitHub 时，双击 `PUSH-TO-GITHUB.cmd`，再创建、合并 PR。推送和合并不会自动部署服务器。

同一成功包再次运行不会重复部署、迁移或发通知。若仅通知失败，状态为 `notification-pending`；再次运行同一入口只重试通知。

双击 `ROLLBACK.cmd` 恢复本次更新前的应用镜像与部署索引，保留所有当前用户数据、Todo 和既有密钥。回滚后旧版没有 Todo 页面，且旧版的账号删除保护可能因新表而暂停，需要重新安装本版后删除账号。存在未完成删除或临时密码待修改时，回滚会停止。后续已升级或修改部署索引时，也会停止以保护新版本。

运行记录：`/opt/garyhub-update-v1.3.5.0-r1/deployment-state.json`。同目录 `private-backup/` 含正式数据库、配置及可能的 TOTP 密钥，只保留在受限服务器备份中。应用回滚不会用历史数据库覆盖上线后的新数据。

本开发环境未连接你的生产 SSH 或执行 Windows PowerShell。真实 Docker 构建、环境与挂载、HTTPS 和通知人数由安装器现场验证，通过后才报告 COMPLETE。
