# GaryHub v1.4.0.0 升级

适用基础：两个生产服务均已部署 **v1.3.6.1**。支持既有“有 TOTP / 无 TOTP”能力组合；不是从任意历史版本跳升的安装包。

## 安装

1. 把 ZIP 完整解压到普通文件夹，不要在压缩包里直接运行。
2. 双击 **RUN-UPDATE.cmd**，使用现有 SSH 私钥口令。默认服务器、私钥和本机仓库位置沿用之前设置。
3. 程序依次核验版本/源码/有效配置，离线构建候选镜像，运行隔离测试，备份数据，切换，验证 HTTPS，发布并核对站内更新通知。
4. 成功应显示 `8/8 COMPLETE GaryHub v1.4.0.0` 和实际通知账号数。保存末尾输出，供核对真实部署结果。

本次已通过 DOM、两种能力组合的 Node20 HTTP、通知去重及部署保护自动检查。可用浏览器连接失败，真实桌面/手机排版、动画观感与帧率尚未验收；安装后需查看 Tools 页面。Windows PowerShell 5.1 的真实双击与生产 Docker 切换也只能在你的环境中验证。

## 本次功能

- 缩小顶部标题区域；工具改为各自独立的本地 SVG 图标。
- 默认多行网格，可切换单行 Dock；保存本机布局偏好。
- 中文、英文、简称和用途搜索；名称与下方简介随全站语言切换。
- 鼠标靠近时图标与邻近图标按距离平滑放大、复位；简介切换不排队。
- 图标下保留名称和简短用途；点击直接进入。触屏不使用悬停放大。
- 键盘 Tab、方向键、Home/End、Enter 可浏览进入；Escape 清空搜索。
- 单行放不下时可水平滚动或用两侧按钮浏览；支持减少动态效果设置。
- 保留原粒子背景、日夜主题、登录流程、工具链接与各用户数据。

## 完成后的核对

访问 Tools：中/英、日/夜、多行/单行各查看一次；搜索“验证码 / PDF / MD / 图片”，清空后应恢复工具。鼠标快速划过图标，检查有无跳动和裁切。手机检查图标名称、横向浏览、页面宽度及直接进入。语言切换不应清空搜索或改变布局。

## 回滚与重试

需要回滚时，双击 **ROLLBACK.cmd**。恢复此前应用镜像，保留当前用户记录与凭据；不会把旧数据库覆盖回去。若之后已有其他部署，程序停止以保护后续改动。

出现 `STOPPED` 时保存末尾输出，不跳过核验。仅通知待发布时可运行同一安装器重试；它不会重复部署健康应用或重复创建通知。

## 源码与 GitHub

安装器会在现有仓库之外的独立 worktree 准备本次源码分支，保留原工作区。双击 **PUSH-TO-GITHUB.cmd** 才会普通推送并打开 PR 页面；需要维护者审阅并合并 main。GitHub 合并与服务器部署分别记录。

自定义参数：

```powershell
& '.\Install-GaryHub.ps1' -Repo 'D:\Codes\Own_Project\garyhub-repo' -KeyPath "$env:USERPROFILE\.ssh\garyhub_interserver_ed25519"
```

检查状态以服务器 `/opt/my-services/garyhub-active-deployment.json`、实际镜像与最终输出为准。本包不包含生产数据库、私钥或私人配置。
