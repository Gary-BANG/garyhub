## r1 现场结果与 r2 修正

2026-11-10 维护者运行 v2.4.0.3-r1：第 1、2 阶段通过，第 3 阶段隔离检查在 `sites-http.cjs` 停止（`ERR_ASSERTION`，`actual=false; expected=true`）。停止发生在备份和切换之前，生产仍为 v2.4.0.2，未发布通知。

原因：r1 沿用 v2.1.0.0 的 `sites-http.cjs`，它在最后一步要求主页包含不带 `target` 的原样链接 `<a href="https://sites.garyhub.uk/"><strong>Elsewhere ↗</strong>`；本版给这条链接加了 `target="_blank" rel="noopener"`，断言因此失败。打包前只核对了该套件读取外站页链接的正则，漏看了这一条主页断言；本机没有 Node，套件无法在打包前实际运行。应用代码没有问题，是检查与本版的预期行为不一致。

r2 的修正：

- 新增本版自己的 `scripts/releases/v2.4.0.3/tests/sites-http.cjs`（v2.1.0.0 的文件保持原样）：主页断言改为带 `target="_blank" rel="noopener"` 的链接；外站页的链接正则同样要求这两个属性，并核对页面上每个 `class="site"` 链接都被匹配到。其余 CSP、缓存、404 隔离断言不变。
- 适配器测试新增一项：把全部隔离套件里“整段 HTML 字面量”的断言与本次提交的页面逐条比对，没有 Node 也能在打包前发现同类不一致。用它复查了其余九个套件，没有发现其他受本版影响的断言。
- 新套件的页面内容断言（脚本与样式版本、无内联脚本、两条链接及缩略图地址、主页链接）在 Chromium 中对提交的文件逐条求值，全部成立；套件本身可解析。HTTP 层的断言仍须由安装器执行。
- 安装器修订号改为 r2。r1 在服务器上留下的 `/opt/garyhub-update-v2.4.0.3-r1` 目录不影响 r2。
