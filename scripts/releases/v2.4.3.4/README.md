# GaryHub v2.4.3.4 · 大富翁：电脑的判断标准与破产清算

源码基于 main `2c51ae729aa8047c30e1f5624cbeb3f6ff1b6e71`（PR #54 合并的 v2.4.3.3），独立分支 `update/garyhub-v2.4.3.4`。本版尚未部署服务器。

## 本版内容

- **破产清算**：付不起钱时，房子半价、地六成、已抵押的地一成卖给银行，连同现金付给债主，最多到欠款；地产退回银行，之后谁停在上面都可以买。之前开的房间仍把地产交给债主。
- **电脑留钱**：底线加前方期望过路费（新手看下一掷，普通与精明看两掷，含场上倍数；精明再加最贵一格的 25%），上限为总资产 35%；三档都能盖到酒店，都会拦人凑组，新手不再随机放弃。
- **电脑交易**：按剩下的回合估算地的过路费（自己的算 30%，对方从自己这里收的算 60% × 威胁系数）；缺钱时现金权重升到 2；门槛新手 0、普通 5%→20%、精明 10%→25%（打到 60% 后保持）；还价补足差额（+5%／+15%），不会出得比第一次少。
- **电脑主动**：缺钱时把地卖给用得上的人（新手可吃亏两成）；普通和精明缺一到两块时向持有人要（先看互换，再出现金）；精明后半局分别向两人收购同一组。
- **拍卖**：留一半底线时跟到地价的 70%／85%／95%。

没有新表、没有新依赖，Compose、环境变量与 Caddy 均不变；只改 `play-monopoly.js` 与 Lab 的 `monopoly.js`；`app.js` 与 `server.cjs` 只改版本号。

详细说明见 `docs/GARYHUB_V2_4_3_4.md`。

## 安装、回滚与源码

完整解压 `GaryHub_v2.4.3.4_upgrade.zip`，在 Windows 双击 `RUN-UPDATE.cmd`。两服务必须实际运行 **v2.4.3.3**（本版交付时未取证生产是否已升级到 v2.4.3.3）。

- **核对链**：`deploy.py` 以 `prior_0433.py` 载入 v2.4.3.3 适配器（再到 v2.4.3.2、v2.4.3.1…），沿用其全部核对。
- **Caddy**：第 1 阶段只读核对 `games.garyhub.uk` 站点块仍在；不写入、不恢复。
- **第 6 阶段新增核对**：两个运行容器中的本版文件（`play-monopoly.js` 的分批收购、本版通知；Lab `monopoly.js` 的新理由）；游戏资源哈希组的文件列表不变，只有 `/play/monopoly.js` 的哈希更新。
- **隔离检查**：二十组，新增 `tycoon-bots-http.cjs`。
- **站内通知**：一条（home）。

`ROLLBACK.cmd` 恢复 v2.4.3.3，保留当前记录与设置；回滚后新开房间的破产回到旧规则。`PUSH-TO-GITHUB.cmd` 只推审查分支，不合并 main。

构建：`python scripts/updater/manage.py build --release 2.4.3.4 --output <ZIP绝对路径>`。验证范围见 [TEST-RESULTS.md](TEST-RESULTS.md)。
