## 白日梦想家

- **开局**：发起人设置 10–20 个金额或礼品（16 个图标，可选填估值，只用于排序），选择币种和第一轮揭开的盒子数（0 到 N−2），输入对方用户名邀请（不提供账号目录，只列出一起玩过的人）。
- **封箱**：服务器用 `crypto.randomInt` 打乱，只公布 SHA-256 指纹（盐 + 顺序）。任何一方都看不到未揭开盒子里的东西。
- **轮次**：发起人决定每轮揭开几个，参与人挑选揭开哪几个；发起人出价时同时定好“若不卖，下一轮揭开几个”，参与人拒绝后可以直接继续。每轮揭完后，除参与人的盒子外至少还剩一个；只剩一个时是最后一次出价。
- **揭晓**：成交，或拒绝最后一次出价后，发起人逐个揭开（可自动依次揭开），最后揭晓参与人的盒子。结束后公开盐和顺序，页面自动核对指纹；发起人可标记“已兑现”。
- **并发与权限**：每一步是一条带修订号的条件更新，过期的页面或重复点击得到 409；只有对局双方能读取，只有轮到的一方能走对应的步骤。
- **通知**：轮到谁时，谁收到站内通知（主页铃铛），推送跟随“事项提醒”的推送设置与免打扰。30 天无进展的对局过期；参与人账号已删除的对局由每小时清理移除。
- **界面**：夜空与晨曦两套配色；3D 翻转的礼盒、奖池牌（揭开即划掉）、信封式报价、最终揭晓动画与彩带，支持中英文、手机布局和“减少动态效果”。
