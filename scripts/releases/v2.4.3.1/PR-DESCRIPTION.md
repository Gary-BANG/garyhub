# GaryHub v2.4.3.1 · 合作小车

游戏厅实时房间新增双人游戏“合作小车”（设计稿第 5 节的第一版）。没有新表、新依赖，不改 DNS、Caddy、Compose；`app.js` 与 `server.cjs` 只改版本号。

## 玩法

- 一人只管方向（◀ ▶ / ← → / A D），另一人管油门、刹车（↑ ↓ / W S）和每关 2 次氮气（空格）；房主选择谁负责方向，可开“宽松模式”。
- 3 关：直道起步、S 弯与锥桶、窄桥与跳台（窄桥超过 36 km/h 半秒会滑下去；跳台至少 58 km/h；油污转向只剩三成）。
- 3 颗心（锥桶扣一颗，之后 1.5 秒无敌）；离路面太远、掉下桥或没冲过缺口：回到检查点并扣 3 秒；到终点 1 星，标准时间内 +1，未丢心 +1；时间或心用完失败。
- 油门手有前方提示与小地图，方向手有锥桶与急弯提示；五个快捷呼叫在两人屏幕弹出并响一声；画面下方显示对方正在做什么。
- 结束后房主可“再试一次”“下一关”（直接开始）或“回到大厅”；房间记录每关最好成绩。

## 同步

- 服务器为准：每秒推进 20 次（物理每秒 60 步），每次向两人发一帧（约 200 多字节）；操作走 `in` 消息（不回复、不存盘、最新为准，只接受该座位负责的字段），呼叫走 `say`；两者有单独额度（突发 60、每秒 40，多余的丢弃不断线）。只有出界、撞锥、捡币、过检查点、倒数结束等时刻存盘并发送完整状态。
- 页面晚 110 毫秒绘制并在帧间插值，本机按键立即显示；“操作回显”显示按下到服务器帧回应的中位毫秒数。
- 一方掉线立即松开其按键，3 秒后暂停（文字游戏仍为 10 秒），回来后倒数 3 秒；网页隐藏或失焦时本机也松键。
- 物理与赛道是一个文件：Calendar 运行 `play-car-sim.js`，页面加载逐字节相同的 `games/play/car-sim.js`；单元测试、适配器测试和安装后的容器核对都比较两者。
