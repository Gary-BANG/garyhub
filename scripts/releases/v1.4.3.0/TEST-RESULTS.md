## 生产和真实 Cloudflare 边界

v1.4.3.0 源码已准备并在本地验证。本次未向真实 GitHub 推送或合并该版本；已收到用户运行 r1 的现场失败日志，但没有 r2 部署完成证据，也未持有/配置真实 R2 凭据。

本地没有 Docker daemon，未声称已完成真实 Docker 镜像构建、Compose 切换或生产回滚；对应运行时保护由继承的模拟回归验证，现场安装器仍必须执行实际离线构建、隔离数据测试、备份、迁移干跑、切换、HTTPS/健康检查、通知人数与去重核验。没有实际部署输出前不标记上线完成。

真实 R2 的网络、桶权限、浏览器 CORS、费用及用户 MP3 必须由 SETUP-R2 和指南现场验收。Setup 工具验证失败会恢复原配置；基础应用可先以默认音乐使用。回滚保留新增音乐数据及凭据，旧版本不消费 R2 删除队列，恢复新版本后继续清理。
