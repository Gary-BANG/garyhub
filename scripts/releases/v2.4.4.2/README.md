# GaryHub v2.4.4.2-r1 升级说明

本包从 v2.4.4.1 更新 Calendar 与 Tools/Lab。个人网站导航可以在当前浏览器保存题库副本，下次直接点卡片名称打开。

1. 在已配置 GaryHub 更新器和 SSH 密钥的 Windows 电脑上完整解压。进入 GaryHub-v2.4.4.2-r1，双击 `RUN-UPDATE.cmd`。
2. 等待安装器报告 `8/8 COMPLETE GaryHub v2.4.4.2`。安装器核对两个服务的版本、能力组合和文件，执行隔离测试、备份、切换、HTTPS 验证和站内发布通知。
3. 刷新 Tools → 个人网站导航。已有题库若显示「待关联本机文件」，打开卡片，选一次原文件夹或 ZIP，勾选「在此浏览器保留副本」，点「关联并打开」。下次直接点题库名称。
4. `ROLLBACK.cmd` 恢复上一版应用并保留当前记录。`PUSH-TO-GITHUB.cmd` 用于另行同步源码审查分支。

已经运行 v2.4.4.1 的服务可直接使用本包。如运行 v2.4.4.0，先安装 v2.4.4.1-r1。详细说明见同目录的 [版本说明](GARYHUB_V2_4_4_2.md)、[验证记录](GARYHUB_V2_4_4_2_TESTS.md)和[项目档案](PROJECT_CONTEXT.md)。
