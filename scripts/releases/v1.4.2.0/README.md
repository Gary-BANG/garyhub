# GaryHub v1.4.2.0 升级包（安装器 r4）

r4 修正隔离测试的 Origin 配置，并统一本地与安装现场的测试环境；失败时标明具体步骤及精简诊断，临时容器日志保留在服务器私有日志中。按 r3 原配置已在本地复现模拟登录 403，修复后两种能力组合通过。r3 还包含按真实连接识别 Reading/数据库/Files/Status 的修复。你提供的 r3 输出停在第 3 步，尚未切换正式服务，无需回滚；完整解压 r4 到新目录后再次双击 RUN-UPDATE.cmd。

适用于服务器两个 Web 服务都实际运行 v1.4.1.0 的情况。已有 TOTP 和无 TOTP 两种能力组合分别保留。源码准备完成不等于服务器已上线。

1. 下载并完整解压本 ZIP，保留全部文件和子目录。
2. 双击 `RUN-UPDATE.cmd`。使用原 Windows OpenSSH、现有 SSH 私钥和已核对的主机记录；需要时输入原私钥口令。默认服务器及仓库路径沿用上一版。
3. 等待检查、离线构建、隔离测试、备份、切换、HTTPS 验证和站内通知核验完成。成功显示 `COMPLETE v1.4.2.0` 及实际通知人数。
4. 需要恢复时双击同一目录的 `ROLLBACK.cmd`。恢复 v1.4.1.0 应用和相关配置，保留当前用户数据。后续部署或受保护配置变更时会停止覆盖。

本次安装会短暂切换 Calendar/Tools/Reading，并为启用统计重启一次 Xray，VPN 会短暂重连。未知服务器配置或源码不匹配时会停止；请保留末尾 `STOPPED` 输出，勿跳过校验。

新增管理员 Server Monitor；Files/Status 仅管理员；Reading 对管理员与订阅账号开放并沿用 GaryHub 登录。旧 Reading 内容保留，可在 Tools 下的 Reading 使用说明中用原 API Token 关联。API Token 不保存，未关联不影响新阅读空间使用。

Calendar 等五页新增每日金句，Research 增加粒子，粒子页面新增原创轻音乐。音乐默认尝试播放，浏览器阻止时点击明暗切换左边的唱片；手动关闭后会记住。VPN 指标从采集启用后累计，“近期活动”不等于精确在线人数。

详细功能和指标说明包含在源码文档 `docs/GARYHUB_V1_4_2_0.md`，验证记录在 `TEST-RESULTS.md`。无需单独安装服务器运行依赖。首次检查会使用服务器已有的 Miniflux/PostgreSQL 镜像运行一次独立认证验收。

如要同步 GitHub，双击 `PUSH-TO-GITHUB.cmd`；它使用独立审查分支，保留原工作区，不强推，也不自动合并 main。安装后自动进行的本地源码准备同样保留已有工作。
