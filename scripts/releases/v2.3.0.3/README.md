# GaryHub v2.3.0.3-r1 upgrade

完整解压 ZIP 后，在 Windows 双击 RUN-UPDATE.cmd。安装器复用已有的 OpenSSH 和 SSH 密钥，要求 Calendar 与 Tools/Lab 都实际运行 v2.3.0.2，并分别核对有 TOTP 和无 TOTP 两种组合的源码。不匹配时直接停止，不能跳过校验。

本次更新网站伙伴布丁（订阅用户与管理员可选）：
- 布丁改为分层矢量骨骼角色：耳朵、尾巴分段挂在弹簧上，随拖动、下落和落地甩动；被拎起时腿会晃。
- 平时会呼吸、看鼠标、眨眼，并随机打哈欠、摇尾巴、东张西望、抬爪、吐舌头喘气、甩耳朵；聊天时挥手、歪头、摇头。
- 鼠标在头上来回划（手机上手指在头上来回滑）就是摸摸头：眯眼、吐舌头、快速摇尾巴。
- 一分钟没人理会趴下睡觉，鼠标靠近或点击就醒来并打个哈欠。
- Calendar、Lab 等安静页面只保留呼吸、眨眼、弹簧摆动和摸头。

新增 companion/puppet.js，boot.js 在 pet.js 之前加载它；米露和栗栗的动作不变。只替换静态伙伴文件和各页面的版本引用，不改数据库结构、Caddy、DNS 或 Compose；设置和用户记录保持不变。安装器依次执行来源与有效配置核对、离线构建、合成数据隔离验证（沿用 v2.3.0.0 的 7 项检查）、备份并切换、HTTPS 与资源核对，并向全部已批准且启用的账号（含管理员）发布站内通知、核对人数与去重。

安装后：以订阅或管理员账号在伙伴面板“换个伙伴”选布丁，切到重力模式从高处松手看耳朵和尾巴；鼠标在它头上来回划几下；放置一分钟看它趴下睡觉。

ROLLBACK.cmd 恢复 v2.3.0.2 应用，保留当前记录与设置；布丁回到整张姿态图。如果之后又有部署，回滚会停止。布丁旧的姿态 SVG 仍留在服务器上，但不再被引用。

PUSH-TO-GITHUB.cmd 以 v2.3.0.2 源码提交 `9c61d24` 为基础准备分支 `update/garyhub-v2.3.0.3`。v2.3.0.1／v2.3.0.2 尚未合并到 main 时，请先不要运行；先合并审查分支 `update/garyhub-v2.3.0.1`（它已包含本版提交）。

功能说明见 docs/GARYHUB_V2_3_0_3.md，验证记录见 docs/GARYHUB_V2_3_0_3_TESTS.md。请保存最终的安装输出，用于核对生产结果。交付升级包不代表已经上线。
