# GaryHub v2.4.0.1 · A 股行情

订阅用户在 Tools → A 股行情中按简称或代码选股。详情显示换手率、量比、振幅、市盈率（TTM）、市净率、总市值与流通市值；展开五档盘口可查看买卖一至五档的价格（元）与挂单量（手）。报价附北京时间。

- 盘中分时显示源站最近交易日的分钟成交价，休市时保留该交易日日期。午休分段，点按图表或用方向键查看某一分钟。
- 近月日 K 显示最近最多 22 个交易日的开高低收、成交量（手）和 MA5/10/20。最多请求 41 根日线供均线计算，历史不足的部分显示“—”。北交所优先使用东方财富按股前复权日线。发生回退时以实际来源和复权标签为准。
- 公司财务可切换最近最多四份已披露的定期报告。营业总收入、归母净利润及其同比分别显示，加权 ROE 和经营活动现金流量净额采用报告期累计口径；显示原报告币种、报告截止日和公告日。缺失显示“—”，保留负值和零。
- 搜索只查证券目录，报价和五档共用一次按股请求。需要看分时、日 K 或财报时展开相应区域。页面可见时每分钟刷新当前报价和展开的分时。报价/分时可复用 30 秒，日线 5 分钟。内存缓存最多 512 项，闲置约 20–21 分钟清除。每人最多 3 组 × 5 只，同一股票限一个组；数据库只保存收藏关系与版本。
- 使用腾讯行情、东方财富公开接口。可用性依赖上游及部署地区；未核实这些接口对订阅用户展示行情的授权。

## 安装与回滚

完整解压并双击 RUN-UPDATE.cmd。两服务须已运行 v2.4.0.0。安装器核对源码、能力与部署索引，离线构建、运行隔离测试并备份；健康检查完成后按策略发布站内通知。ROLLBACK.cmd 恢复到 v2.4.0.0，保留当前账户及收藏。GitHub 和生产状态分别核验。

本包为 v2.4.0.1-r2。生产 v2.4.0.0 已成功部署，日志核验 8 个通知接收账号。只需修复 v2.4.0.0 的源码同步时，使用独立的 GitHub 源码修复 ZIP，解压后双击其 PUSH-TO-GITHUB.cmd。

升级到 v2.4.0.1 时，运行本包 RUN-UPDATE.cmd。其 Windows 源码步骤根据已拉取的 origin/main 匹配完整 Git 文件树：PR #38（v2.3.2.3）可直接同步至 v2.4.0.1，若 v2.4.0.0 已合并则只导入后续差异。两种方式都使用新的审查分支。在校验并提交后才建立分支。遇到其他文件树时保留工作区并停止；目标内容相同则直接结束。

安装成功后，若要提交 GitHub，在本包双击 PUSH-TO-GITHUB.cmd，再到 GitHub 创建并合并 PR。旧分支及工作目录留存，两个修复包均无需手动清理旧分支。已通过 r1 安装 v2.4.0.1 的环境只运行源码入口，服务器回滚使用实际安装的那一版包。
