## 执行边界

开发环境使用 Node.js v24.19.0 与 sqlite3 6.0.1。正式服务仍沿用当前 Node.js 20 镜像，不重新安装依赖；安装器在该实际镜像中重新运行隔离联调和关键单元测试，通过后才切换。

生产 Docker 构建、真实配置、邮件服务连通性、备份、实际数据副本迁移、正式 HTTPS 和通知人数尚需由用户运行安装器现场验证。本环境没有执行 Windows PowerShell 或生产 SSH，不将获得 ZIP 视为已经上线。真实找回邮件到达用户邮箱仍需上线后实际使用验证。

回滚测试使用模拟服务调用与真实临时SQLite数据，不等同于已经在 VPS 执行 Docker 回滚。当前数据已有CAD/HKD时停止旧版降级，避免产生无法读取的账目。
