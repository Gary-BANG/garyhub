# GaryHub v2.3.2.1 · 学习中心与个性化

发布日期 2026-11-06（America/Chicago）。安装器 v2.3.2.1-r1 从 v2.3.2.0 升级；审阅基线为 PR #35 合并提交 `c5c0b864b49bd7ff53516380f48caf12da6cf281`。

## 使用

- 学习中心左栏的书本图标打开课程列表，列表图标打开本讲目录。点已打开的图标收起面板。目录标题右侧的两个图标分别控制目录层级和全部正文。提示文字和无障碍名称随语言切换。
- 目录下方显示当前讲义的阅读进度、百分比和提示。视口底边到达正文末尾时显示 100%。向上滚动、跳转、切换讲义或折叠正文会重新计算。课程的“已学习／学习中／未学习”由用户自行设置。
- 首页、Tools 及学业页的账号头像进入独立的 [个性化页面](https://tools.garyhub.uk/personalize/)。旧地址 `/study/?personalize=study` 也会前往新页。当前设置区为学习中心，提供墨夜、纸白、暖纸与两种字号预览。点击保存写入当前账号。
- 独立页面通过 `/api/academic/preferences` 读写阅读设置。服务器只返回设置、账号编号和修订号。保存时保留课程、讲义、成绩及其他字段，校验会话、来源、CSRF、账号与修订号；如果其他页面已修改资料，请刷新后重新设置。复用现有 Tools 域名和有效配置。

## 安装、回滚和源码同步

1. 完整解压 ZIP，在新目录双击 `RUN-UPDATE.cmd`；开头应显示 `Installer v2.3.2.1-r1`。Calendar 与 Lab 的版本必须同时为 v2.3.2.0。
2. 安装器核验两个服务的源文件、能力组合和有效 Compose，在离线构建后执行九组隔离检查；通过后备份、切换、核对 HTTPS 和文件哈希，向全部已批准且启用的账号（含管理员）发布未读通知并检查去重。
3. 回滚使用同一目录的 `ROLLBACK.cmd`，恢复本次安装前的 v2.3.2.0 应用并保留当前用户记录。
4. `PUSH-TO-GITHUB.cmd` 将源码导入独立 worktree，向审查分支普通推送，由维护者审阅合并。

本地验证范围见 TEST-RESULTS.md。源码已准备；本版推送、合并及生产安装需另行确认。
