# GaryHub v2.4.0.0 验证记录

两种部署组合分别启动 Calendar 和 Tools/Lab 本地进程，使用独立 SQLite 合成账号，运行本包的十组 HTTP 检查。股票页面、受限资源、查询接口、跨账号写入、Origin、CSRF、限额、重复、并发竞争及删除通过。九组既有回归通过。历史伙伴测试在本机通过 APP_DIR 读取容器内对应的资源。生产安装时仍执行离线容器隔离检查。

缓存单测通过：名称检索不触发行情查询，同代码并发合并，30 秒新鲜度，失败时标示旧报价，闲置过期后释放。前端 DOM 检查覆盖搜索、查看行情、展开日 K、新建分组、收藏、移出与删除。Chromium 启动受系统限制，未完成真机视觉验收。

使用实际数据源检查了深圳 300033、上海 600000 和北京 920185 的搜索、报价与日线。上游返回的日线条数可能少于 22。可用性取决于源站以及部署服务器网络。未核实第三方行情向订阅用户展示的授权范围。

合成库验证发布通知人数及重复发布。Windows 双击、服务器 Docker 切换、真实回滚与生产通知人数待现场日志。GitHub 源码同步和生产升级分别进行。
