# GaryHub v2.4.0.0

新增独立 A 股行情工具。订阅用户可按代码或名称查行情、查看近月日 K，创建最多 3 个分组，每组 5 只股票。临时行情仅缓存在内存。

完整解压后双击 RUN-UPDATE.cmd，要求两服务已运行 v2.3.2.3。ROLLBACK.cmd 回到 v2.3.2.3，保留业务数据。PUSH-TO-GITHUB.cmd 从审阅的 v2.3.2.2 main 构造包含 v2.3.2.3 的累积审查分支。服务器部署与源码同步独立。

从 Tools 打开 A 股行情。东方财富提供代码检索，腾讯提供按股报价和日 K。显示行情时间；源站故障会提示或标记上次行情。页面可见时刷新，报价复用 30 秒，闲置缓存最多约 20–21 分钟清除。每个账号只持久化分组。
