# GaryHub v2.4.0.4

学习中心讲义答疑的授权改为随提问续期：授权后有效一小时，每次提问都从提问时起重新计一小时，连续一小时不提问才过期；已过期的授权不会被提问恢复。面板计时器随提问和服务器返回的 expiresAt 重设，授权说明同步修改。

基于 main 0a5e86e（PR #41），复用共享更新器并注册自己的 v2.4.0.4-r1 适配器，严格要求实际运行 v2.4.0.3。无数据库结构、依赖、Caddy 或 Compose 变化。构建机没有 Node 与 Docker：实际 assistant-tutor.js 与 panel.js 已在浏览器中运行验证续期，适配器 10 项和共享更新器检查通过；Node 单元测试未在本地运行，十组隔离 HTTP 检查由安装器在现场执行。完整验证与现场限制见 docs/GARYHUB_V2_4_0_4_TESTS.md。

源码已准备、本地验证；生产部署由升级 ZIP 完成，GitHub 合并不代表已上线。
