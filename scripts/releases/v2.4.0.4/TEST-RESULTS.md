## 服务端：实际 `assistant-tutor.js` 在浏览器中运行

本地页面（仅在 git 忽略的 `dist/` 中，不入库、不进升级包）加载 `calendar-app/assistant-tutor.js` 原文，用最小替身提供 `node:crypto`、`./rate-limit` 和 Express 式路由，再逐步重放单元测试。16 项全部成立：

- 授权返回的 `expiresAt` 为授权时起一小时；一小时不提问后提问返回 `consent`，且不调用模型。
- 第 59 分钟提问成功，返回的 `expiresAt` 为该时刻起一小时；第 118 分钟（已超过原来的一小时）提问仍成功；之后一小时不提问再提问返回 `consent`。
- 已过期的授权再次提问仍为 `consent`，不会被续期。
- 原有用例不变：重启后须重新授权、额度用完、AI 关闭、回答期间降级／停用账号会退回额度且永久撤销、回答期间过期会退回额度、同一授权并发提问被拒绝。

替身不是 Node／Express，本项证明的是模块逻辑，不代替 Node 20 下的运行。
