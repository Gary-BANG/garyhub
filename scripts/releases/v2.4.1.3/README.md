# GaryHub v2.4.1.3 · 统一页头、今日面板、全站搜索与日常提醒

源码基于 main `2d1977503a74d921e7c4f6005e181c46da14ca6f`（PR #45 合并的 v2.4.1.2），独立分支 `update/garyhub-v2.4.1.3`。源码准备、本地验证、GitHub 合并与生产验证分别记录；本版尚未部署服务器。

## 本版内容

- **界面**：
  - 统一标志、页头和按钮形状（`brand.css`）；手机页头收成一行，导航进菜单（`hub-nav.js`）。
  - 站点图标与 manifest，可添加到主屏。
  - 主页登录后的“今日”面板。
  - 全站搜索（Ctrl/⌘+K 或 /）。
  - 登录页说明登录后去哪里。
  - 图片消除、Markdown 预览、PDF 浅灰免登录。
  - 开发者页对没有授权的访客显示公开卡片。
- **功能**：
  - 只读日历订阅（ICS）。
  - 浏览器推送（事项提醒、到价提醒）。
  - 账本月度预算、六个月趋势与 CSV 导出。
  - A 股到价提醒（普通 3 个，VIP 20 个）。
- **数据库**：新增六张表，均无指向 users 的外键，回滚时保留不用。没有新依赖，Caddy、Compose 和环境变量都不变。

详细说明见 `docs/GARYHUB_V2_4_1_3.md`。

## 安装、回滚与源码

完整解压 `GaryHub_v2.4.1.3_upgrade.zip`，在 Windows 双击 `RUN-UPDATE.cmd`。两服务必须实际运行 **v2.4.1.2**（2026-11-16 两个 `/health` 均返回 2.4.1.2）。版本、源码、能力组合或有效 Compose 不匹配时，安装器在改动前停止。

- **核对链**：`deploy.py` 以 `prior_0412.py` 载入 v2.4.1.2 适配器，经 v2.4.1.1、v2.4.1.0、v2.4.0.4 沿用全部核对与 curl 重试。
- **唯一替换的旧检查**：共享运行时要求三个本地工具对访客跳转登录；本版改为核对访客得到页面且带 CSP。
- **私有档案**：新镜像基于正在运行的镜像构建，私有开发者档案随镜像保留，包内不含私有文件。
- **隔离检查**：十二组，`useful-http.cjs` 换成本版，新增 `extras-http.cjs`；推送打到套件内的假推送服务。
- **第 6 阶段新增核对**：
  - 主页、工具台和登录页的新标记；
  - 新接口的登录门（401）与 Origin 门（403）；
  - 伪造的订阅地址返回 404；
  - 三个主机的 manifest；
  - 两个运行容器中的新文件；
  - Calendar 数据库中的新表（只读查询）。
- **站内通知**：三条（home、calendar、tools），核对人数与去重。

`ROLLBACK.cmd` 恢复 v2.4.1.2 应用和有效配置，保留当前用户记录与设置。`PUSH-TO-GITHUB.cmd` 使用独立 worktree 和审查分支，不强推、不自动合并 main。

构建：`python scripts/updater/manage.py build --release 2.4.1.3 --output <ZIP绝对路径>`。验证范围见 [TEST-RESULTS.md](TEST-RESULTS.md)。
