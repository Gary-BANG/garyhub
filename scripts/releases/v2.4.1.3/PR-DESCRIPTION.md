# GaryHub v2.4.1.3

本 PR 按维护者 2026-11-16 选定的改进清单实现以下内容。

## 界面

- **统一页头**：全站使用同一个行星标志、页头结构和按钮形状（`brand.css`）。手机上页头收成一行，导航进菜单（`hub-nav.js`）。
- **站点图标**：新增站点图标和 manifest，可以添加到主屏。
- **今日面板**：登录后，主页第一屏是“今日”面板（日程、待办、在读讲义、未读通知）和入口卡片。
- **全站搜索**：Ctrl/⌘+K 或 `/` 打开。工具和页面在浏览器内匹配，个人记录只查当前账号。
- **登录来由**：登录页说明登录后将前往哪个页面。
- **免登录工具**：图片消除、Markdown 预览和 PDF 浅灰转换不登录也能使用，CSP 不变。
- **开发者公开卡**：没有授权的访客在开发者页看到一张公开卡片。

## 功能

- **日历订阅**：只读 ICS 地址，服务器只存令牌的哈希，可以重新生成或关闭。
- **浏览器推送**：用 Node 自带 crypto 实现 RFC 8291 加密与 RFC 8292 VAPID，没有新依赖，只接受白名单内的推送服务；事项提醒和到价提醒都会推送。
- **账本**：月度预算、六个月趋势和 CSV 导出。
- **A 股到价提醒**：在订阅门之后，普通账号 3 个，VIP 20 个。
