# GaryHub v2.4.3.2 · 骰子抢宝箱与大富翁

游戏厅实时房间新增两款棋盘游戏（设计稿第 2、3 节的最小可玩版本，另加三档电脑与均衡盖房），棋盘、骰子动画、电脑对手和托管两款共用。没有新表、新依赖，不改 DNS、Caddy、Compose；`app.js` 与 `server.cjs` 只改版本号。

## 玩法

- **骰子抢宝箱**（2–4 人）：固定 7×7 地图、四角基地；掷一颗骰子最多走点数步，带箱少走一步；扛回自己的基地才开箱计分（别人只看见木／银／金材质）；停在别人格子上抢夺（平局防守方胜，站在自己基地 +1）；流沙、尖刺、只有放置者看得见的暗夹；疾风靴、暗夹、护盾、回城卷轴。双人 12、3–4 人 15 金币获胜，或 8／12／16 回合后比金币。
- **大富翁**（2–5 人）：原创 32 格（20 城 7 组、高铁站与机场、机会 10 张、新闻 8 张、税务局、休息站）；初始 15000，对子再掷；买地、过路费、整组翻倍、均衡盖房到酒店；卖房、抵押、卖回银行、破产；15–30 轮后比总资产。没有玩家交易与拍卖。

## 平台

- 游戏可声明 `seatCount(config)`：座位数随房间设置，房主改人数时增减座位（末座有人时不能减少）。
- 游戏可声明 `away: 'autoplay'`：掉线宽限后或连续两次超时，由“普通”电脑托管该座位，座位旁显示“托管”；本人发 `takeover` 接管（也可主动托管）。只有所有真人都离开才暂停，恢复时仍不在的人继续托管。托管状态随房间存入 `play_rooms`。
- 电脑（新手、普通、精明）只看公开视图：宝箱金额、别人的暗夹和道具、牌序都不下发。
- 页面共用 `games/play/board.js`（格子棋盘、棋子逐格走、骰子滚动；动画按状态序号只播一次）。
