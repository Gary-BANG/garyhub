# GaryHub v2.4.3.2 · 骰子抢宝箱与大富翁

源码基于 main `81ec1923e3d1ce8cecd2b3d8cbd935ba10d4e198`（PR #52 合并的 v2.4.3.1），独立分支 `update/garyhub-v2.4.3.2`。本版尚未部署服务器。

## 本版内容

- **骰子抢宝箱**（游戏厅实时房间，2–4 人）：7×7 地图，四角基地；掷一颗骰子走不超过点数的步数，捡宝箱扛回自己的基地才开箱计分（带箱每次少走一步），停在别人格子上发起抢夺；流沙、尖刺、只有放置者看得见的暗夹，四种道具（疾风靴、暗夹、护盾、回城卷轴）。双人 12 金币、3–4 人 15 金币获胜，或 8／12／16 回合后比金币。
- **大富翁**（2–5 人）：原创 32 格地图（20 座城市分 7 组、高铁站与机场、机会、新闻、税务局、休息站）；买地、过路费、整组翻倍、均衡盖房到酒店、卖房、抵押、卖回银行、破产；15–30 轮后比总资产。
- **共用部分**：棋盘与骰子动画（`board.js`）、三档电脑对手（新手、普通、精明）、托管与“接管”：掉线或连续两次超时由电脑代玩，回来后点“接管”；只有所有真人都离开时才暂停，恢复时仍不在的人继续托管。座位数由房间设置决定，房主可改人数。
- **入口**：游戏厅大厅新增两张卡片；房间页新增两个游戏选项；站内搜索与小布丁认识两款新游戏。

没有新表、没有新依赖，Compose、环境变量与 Caddy 均不变；`app.js` 与 `server.cjs` 只改版本号。

详细说明见 `docs/GARYHUB_V2_4_3_2.md`。

## 安装、回滚与源码

完整解压 `GaryHub_v2.4.3.2_upgrade.zip`，在 Windows 双击 `RUN-UPDATE.cmd`。两服务必须实际运行 **v2.4.3.1**（2026-11-21 生产 `/health` 已返回 2.4.3.1）。

- **核对链**：`deploy.py` 以 `prior_0431.py` 载入 v2.4.3.1 适配器（它再载入 v2.4.3.0），沿用其全部核对（含房间 socket 经 Caddy 的 401／403／404 门、两个容器中小车文件哈希一致）。
- **Caddy**：第 1 阶段只读核对 `games.garyhub.uk` 站点块仍在；不写入、不恢复。
- **第 6 阶段新增核对**：三个棋盘脚本的哈希（游戏资源组），以及两个运行容器中的新文件（`play-treasure.js`、`play-monopoly.js`、带“接管”的 `play-rooms.js`、本版通知；Lab 的 `board.js`、`treasure.js`、`monopoly.js` 与放行它们的 `games-host.cjs`）。
- **隔离检查**：十八组，新增 `boards-http.cjs`。
- **站内通知**：一条（home）。

`ROLLBACK.cmd` 恢复 v2.4.3.1，保留当前记录与设置；棋盘游戏房间留在 `play_rooms`，旧版不加载。`PUSH-TO-GITHUB.cmd` 只推审查分支，不合并 main。

构建：`python scripts/updater/manage.py build --release 2.4.3.2 --output <ZIP绝对路径>`。验证范围见 [TEST-RESULTS.md](TEST-RESULTS.md)。
