# GaryHub v2.4.3.0 · 实时房间：词语默契与对战猜数字

源码基于 main `4511bd72a8b4310cb4f61e1e97bb04fa73c140e0`（PR #50 合并的 v2.4.2.0），独立分支 `update/garyhub-v2.4.3.0`。本版尚未部署服务器。

## 本版内容

- **实时房间 `https://games.garyhub.uk/play/`**：创建房间得到 6 位房间码和邀请链接，也可以输入对方用户名发站内邀请；所有人准备后房主开始，每一步房间里的人同时看到。服务器掌握计时；有人掉线 10 秒后计时暂停，回来后接着玩（服务器重启后房间也会暂停恢复）。每人到服务器的延迟显示在房间里，“测一测”可以多测几次。
- **词语默契**（双人合作）：两人同时写一个词，提交后锁定，两人都提交后才同时揭晓；不一样就各写一个能连起上两个词的新词，本局出现过的词不能再用；意思相同时两人都点“算我们一样”也算成功。每轮限时（30/60/90 秒或不限时）、最后 15 秒提醒、连续 3 轮超时停表、轮数上限、可选挑战目标、双方同意才认输、中途离开记为中断。
- **对战猜数字**（双人对战）：各设 4 位不重复的密码，每轮同时猜，xA yB 提示，先猜中者胜，同轮都猜中为平局；超时算这轮没猜，连续 3 轮判负；对方离开 2 分钟后可判胜。房主可以添加电脑对手（新手、普通、精明），电脑只看自己座位的信息。
- **入口**：游戏厅大厅新增两张卡片和“输入房间码加入”；主页“更多”菜单说明、全站搜索和网站伙伴同步更新。

新增一张表 `play_rooms`（无外键，已加入账号删除清单），**没有新依赖**（WebSocket 服务端为 Node 原生实现），Compose、环境变量与 Caddy 均不变。

详细说明见 `docs/GARYHUB_V2_4_3_0.md`。

## 安装、回滚与源码

完整解压 `GaryHub_v2.4.3.0_upgrade.zip`，在 Windows 双击 `RUN-UPDATE.cmd`。两服务必须实际运行 **v2.4.2.0**（2026-11-20 生产 `/health` 已返回 2.4.2.0）。

- **核对链**：`deploy.py` 以 `prior_0420.py` 载入 v2.4.2.0 适配器，沿用其全部核对（含游戏主机的文件、页面、登录门与 CSP）。
- **Caddy**：不改动。第 1 阶段只读核对 Caddyfile 仍有 v2.4.2.0 写入的 `games.garyhub.uk` 站点块（缺失或被改写时停止，不做任何改动）；Caddy 的 `reverse_proxy` 本身会转发 WebSocket 升级。
- **第 6 阶段新增核对**：经 Caddy 对房间 socket 发起握手——无登录 401、外来 Origin 403、tools／主页主机 404；socket 路径的普通 HTTP 404；`/api/hub/play` 在 games 与 calendar 主机需要登录（401），创建房间需要 Origin 与令牌（403）；房间页面与四个脚本样式的哈希；运行容器中的新文件；新表（只读查询）。
- **隔离检查**：十六组，新增 `play-http.cjs`（经 Lab 的真实 WebSocket：双方对局、隐藏词、只发 FIN 的掉线暂停与恢复、电脑对手、邀请通知、删除预览）。
- **站内通知**：一条（home）。

`ROLLBACK.cmd` 恢复 v2.4.2.0，保留当前记录与设置；`play_rooms` 表保留，旧版忽略；Caddy 无需恢复。`PUSH-TO-GITHUB.cmd` 只推审查分支，不合并 main。

构建：`python scripts/updater/manage.py build --release 2.4.3.0 --output <ZIP绝对路径>`。验证范围见 [TEST-RESULTS.md](TEST-RESULTS.md)。
