# GaryHub v2.4.3.0 · 实时房间：词语默契与对战猜数字

游戏厅新增实时房间平台和两款“同时提交、同时揭晓”的游戏。不需要 DNS 或 Caddy 改动，没有新依赖。

## 实时房间

- **连接**：页面经 `wss://games.garyhub.uk/api/hub/play/socket` 连接。Tools/Lab 只在 games 主机、只对这一路径接受升级，原样转发到 Calendar；Calendar 让握手经过 Express 的会话与账号检查（含临时密码 428），并只接受 `https://games.garyhub.uk` 来源。WebSocket 服务端（`play-socket.js`）为 Node 原生实现：只收掩码文本帧、单条 ≤ 8 KiB、心跳 15 秒、45 秒无响应断开、只发 FIN 的对端立即断开。
- **房间**：6 位房间码（无易混字符）、邀请链接、按用户名发站内邀请（每房间 10 次，推送跟随“事项提醒”）；房主可改设置、加减电脑玩家、请人离开（被请离者不能再进）；所有人准备后开始；结束后再来一局，房间累计战绩。每人最多 3 个进行中的房间。
- **同步**：每次变化向每个人推送按座位过滤的完整视图（未揭晓的词与密码只在服务器上）；动作带 id 去重；服务器掌握截止时间，页面用往返时间估算时钟差。
- **断线**：掉线 10 秒后暂停计时，全员回来后继续（至少还剩 5 秒）；同一账号新页面打开时旧页面让出；房间每次变化写入 `play_rooms`，服务重启后进行中的房间以暂停状态恢复。空闲大厅 30 分钟关闭，7 天无进展的对局关闭，结束 180 天的房间与成员账号已删除的房间由每小时清理删除。
- **延迟**：页面每 5 秒测一次往返时间，上报中位数、波动、最快值；房间显示每人到服务器的延迟和“你们之间约多少毫秒”，结果中保留这些数据，供以后的合作小车调手感。

## 词语默契

两人同时写一个词（≤ 12 字），提交后锁定，都提交后同时揭晓；相同（忽略空格、标点、大小写、全半角）即成功；不同则两人都选“算我们一样”也算成功，否则下一轮各写一个连起上两个词的新词。本局出现过的词不能再用。每轮限时 30/60/90 秒或不限时；到时没写的人再给 15 秒，仍没写记超时；连续 3 轮超时停表等 TA 继续；达到轮数上限或双方都认输为失败；中途离开记为中断。结束页有评价、词链与房间战绩。

## 对战猜数字

各设 4 位不重复密码（60 秒内未设随机生成），每轮同时猜，xA yB 提示，先 4A 者胜，同轮都猜中平局；30 轮未分胜负为平局；超时算本轮没猜，连续 3 轮判负；认输；对方离开 2 分钟后可判胜。页面有数字键盘、键盘输入、草稿板（只存本机）。电脑玩家三档，只看自己的猜测与提示：新手（只记得最近 3 条提示、五次里有一次乱猜，约 9 次猜中）、普通（只记得最近 3 条提示，约 7.4 次）、精明（记得全部提示，选最坏情况剩余最少的猜测，约 5.4 次、最多 7 次）。
