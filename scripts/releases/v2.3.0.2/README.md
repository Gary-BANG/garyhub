# GaryHub v2.3.0.2-r1 upgrade

完整解压 ZIP 后，在 Windows 双击 RUN-UPDATE.cmd。安装器复用已有的 OpenSSH 和 SSH 密钥，要求 Calendar 与 Tools/Lab 都实际运行 v2.3.0.1，并分别核对有 TOTP 和无 TOTP 两种组合的源码。不匹配时直接停止，不能跳过校验。

本次更新网站伙伴：
- 栗栗改为和米露一样的分层矢量骨骼角色：会眨眼、摆尾巴、挥手，下落时 o 形嘴，开伞微笑，着地闭眼，起身后露出开心的表情。
- 所有伙伴开伞降落时在着地前收住摆动，落地后脚不再在地面上滑动。
- 整张姿态图角色（布丁、页芽、小航）落地与起身改为淡入淡出，页芽、小航开伞时的大小与站立时一致。

本次只替换静态伙伴文件和各页面的版本引用，不改数据库结构、Caddy、DNS 或 Compose；设置和用户记录保持不变。安装器依次执行来源与有效配置核对、离线构建、合成数据隔离验证（沿用 v2.3.0.0 的 7 项检查）、备份并切换、HTTPS 与资源核对，并向全部已批准且启用的账号（含管理员）发布站内通知、核对人数与去重。

安装后：登录账号，在伙伴聊天面板的设置里“换个伙伴”选栗栗，切到重力模式，从高处拖起后松手，确认落地时闭眼、起身后开心，站好后会眨眼。

ROLLBACK.cmd 恢复 v2.3.0.1 应用，保留当前记录与设置；栗栗回到整张姿态图。如果之后又有部署，回滚会停止。

升级包只能新增或替换文件，栗栗旧的五个姿态 SVG 会留在服务器上，但不再被引用。

PUSH-TO-GITHUB.cmd 以 v2.3.0.1 源码提交 `5a45333` 为基础准备分支 `update/garyhub-v2.3.0.2`。v2.3.0.1 尚未合并到 main 时，请先不要运行；先合并审查分支 `update/garyhub-v2.3.0.1`（它已包含本版提交）。

功能说明见 docs/GARYHUB_V2_3_0_2.md，验证记录见 docs/GARYHUB_V2_3_0_2_TESTS.md。请保存最终的安装输出，用于核对生产结果。交付升级包不代表已经上线。
