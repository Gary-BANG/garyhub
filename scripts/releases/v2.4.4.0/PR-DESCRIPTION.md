## GaryHub v2.4.4.0

在 Tools 增加「个人网站导航」。访客可临时打开 HTML、网站目录、ZIP 或网址。登录后可按需保存书签，在原设备重新打开，支持多入口、相对资源和 PDF 页码。文件内容与浏览器文件句柄都保留在本机。

已关联文件需要重新授权时，当前账号会在通知中心收到带网站入口的未读提醒。提醒按设备、网站和本次失效去重，重新授权后清除。新设备可直接为已有书签关联文件。

## 发布与验证

基于 v2.4.3.4（PR #55，4603993），复用共享更新器，两种 TOTP 能力组合均保留。安装器新增导航隔离检查，旧的 20 组继续执行，更新说明使用 tools 范围。根 README、项目档案、版本清单、发布记录和测试记录已同步。

浏览器已验证真实 ECE 470 网站 ZIP、图片、公式、PDF 指定页、书签持久化和通知操作。详见 docs/GARYHUB_V2_4_4_0_TESTS.md。正式 Windows 安装和生产验证以现场日志为准。
