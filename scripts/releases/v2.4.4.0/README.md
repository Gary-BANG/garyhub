# GaryHub v2.4.4.0-r1 升级说明

本包将 Calendar 与 Tools/Lab 从 v2.4.3.4 升至 v2.4.4.0。安装器会核对现场运行版本、有效配置、挂载与源码摘要，并选择匹配的 TOTP 能力组合。基于现有镜像离线构建。本版沿用已有域名与反向代理。

## 在 Windows 上安装

1. 将整个 ZIP 解压到本机，打开解压后的 GaryHub-v2.4.4.0-r1 目录。
2. 在已配置 GaryHub SSH 密钥和 OpenSSH 的维护电脑上双击 RUN-UPDATE.cmd。按现有方式输入密钥口令。若前置检查停止，请保留最后的 STOPPED 行，便于核对现场状态。
3. 等待 8/8 COMPLETE GaryHub v2.4.4.0。安装器会执行 21 组隔离检查、备份、切换、HTTPS 与文件校验，并核对正式通知人数和重复发布。安装输出才是本服务器的部署记录。
4. 登录后在 Tools 中点「个人网站导航」。首次默认为临时打开，勾选「保存到我的导航」才会创建私人书签。授权失效时在原设备打开 Tools 或导航页，通知中心会提示重新授权，点击通知可定位该网站。

## 数据与恢复

HTML、文件夹及 ZIP 在本机读取，账号仅保存名称、来源类型、相对入口或网址等小量记录。跨设备使用本地书签须重新关联原文件。两张新增 SQLite 表归属账号，沿用原账号数据备份和删除流程。

ROLLBACK.cmd 使用上次安装留下的快照与实际配置恢复 v2.4.3.4 应用，并保留当前用户数据。PUSH-TO-GITHUB.cmd 用于另行同步源码审查分支。包内的 SHA256SUMS.txt 与 TEST-RESULTS.md 分别列出文件摘要和本地验证范围。

更新档案可直接打开同目录的 [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md)、[版本说明](GARYHUB_V2_4_4_0.md)与[完整测试记录](GARYHUB_V2_4_4_0_TESTS.md)。
