# GaryHub v1.4.0.1 鼠标悬停修复

本包用于已安装 **v1.4.0.0** 的服务器。完整解压后双击 **RUN-UPDATE.cmd**，沿用现有 SSH 私钥口令。不需要先卸载或回滚 v1.4.0.0。

## 修复内容

旧版把鼠标事件绑定到 `(hover:hover) and (pointer:fine)` 判断；不满足时整个悬停处理退出，CSS 还强制取消放大。键盘聚焦不受这项限制，因此出现“鼠标无变化，Tab 可以显示介绍”的现象。

新版根据实际鼠标事件响应：移入图标即可放大、文字变色、显示当前语言的简介；不要求点击或键盘聚焦。支持 pointer 与传统 mouse 事件；过滤手指操作产生的模拟鼠标事件；浏览器报告触屏为主要输入设备时，外接鼠标仍可工作。背景、主题、搜索、网格与 Dock 布局保持现有行为。系统开启减少动态效果时，保留变色与介绍，停用放大动画。

HTML 为修复脚本和样式使用新的版本查询参数；安装后按精确 SHA256 校验 HTTPS 返回的 JS/CSS，避免旧资源混用。

## 安装与回滚

安装器核对两个服务均为 v1.4.0.0、源码基线和有效配置，离线构建、隔离测试、备份后切换，验证 HTTPS 资源，再发布并核对未读站内修复通知。成功显示 `8/8 COMPLETE GaryHub v1.4.0.1` 与实际通知账号数。

回滚双击 **ROLLBACK.cmd**，返回 v1.4.0.0 应用镜像，保留当前用户记录。出现 `STOPPED` 时保留末尾输出，不跳过检查；通知待发布可重复运行同一安装器，不重复创建通知。

源码同步沿用独立 worktree；需要推送时双击 **PUSH-TO-GITHUB.cmd**，审阅并合并 PR。程序不覆盖原工作区、不 force push、不自动合并 main。

已在 jsdom 中复现旧版问题，并通过主要设备媒体查询为 false 时的鼠标移入、传统鼠标事件、触屏/鼠标切换、减少动态效果及键盘/语言回归。Node20 的两种能力组合 HTTP、用户数据隔离与通知去重检查通过。
