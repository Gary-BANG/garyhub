开始阅读

Reading 是部署在 GaryHub 服务器上的 Miniflux RSS/Atom 阅读器。进入后添加网站地址或订阅源，就能集中查看更新、分类、收藏和标记已读。每个账号的内容独立。

进入 Reading ↗

此入口沿用 GaryHub 登录。退出整个账号请使用 GaryHub 的退出按钮。

关联已有 Reading 账号

如果你曾单独使用 Miniflux，可用原账号的 API Token 验证归属。Token 可在原账号“设置 → API 密钥”中生成；它只用于这次验证，不会保存。没有 Token 时，新阅读空间仍可使用，原账号内容保留，稍后由管理员协助核对。

关联后将打开旧账号的阅读空间；两个空间不会自动合并。为保护数据，已有不同关联时需管理员核对。
